# 分镜图 Prompt 通用技法

分镜图只表现视频开始时的一张静态画面。它不是动作摘要、结尾预览或第二套分镜创作。

## 输入边界

- V3：`shotDescription`、`shotSize`、可选 `cameraAngle`、`requiredAssets`、短 `videoStyle`。
- V1/V2：原生 `picture` 替代 `shotDescription`，其他字段相同。
- 不使用台词、声音、完整导演规划、轴线图或后续视频参数补写画面。

## 首帧提取步骤

1. 从描述开头寻找直接确认的可见人物、物件、位置、姿态和正在进行状态。
2. 若开头只有动作，倒推该动作成立所必需的最小前态。例如“放下纸箱”只允许得到“人物正持有纸箱”，不能得到其精确左右位置或背景布局。
3. 若依赖相邻镜头交接，只继承相邻正式镜头已经明确且本镜未改变的状态。
4. 一旦得到能自然启动后续动作的最早状态即停止；不得继续取后续更戏剧化或更方便绘制的帧。
5. 按 `shotSize` 删除当前画框无法清楚看见的次要细节；必要 `cameraAngle` 转成可见视角，不扩写轴线理论。
6. 只选择首帧中可辨识且确有约束作用的资产，并按顺序绑定引用。

## 单帧成立条件

- 所有人物、物件、接触点、遮挡和可读内容能在同一时刻成立；
- 不同时出现动作前态与动作结果；
- 不提前出现稍后进场人物、后来拿出的道具、台词内容或声音来源；
- 不把心理、导演意图、时间过程、运镜或视频参数写入图片 Prompt；
- 看不见的信息直接省略，不写“未显示”“画外存在”等解释。

## 媒介与资产

- `videoStyle` 只锁定真人/二维/三维等媒介与稳定轮廓、材质、光色原则；具体场景状态仍来自本镜事实和参考图。
- 人物参考锁定身份和当前确认造型；场景参考锁定可见空间；道具参考锁定外观。
- 参考图不能改变首帧人物数量、时刻、物件状态或媒介类型。
- 没有视觉约束作用的资产不绑定；不得机械复制全部 `requiredAssets`。
- `@ImageN` 必须严格对应 `associateAssetsIds[N - 1]`，不得交换编号或让一个引用代替另一项资产。

## 输出

只输出一段紧凑、可直接生图的纯文本：参考资产及用途（如有）→ 静态画面与构图 → 一句稳定视觉原则（如有）。不得输出分析、Markdown、负面词清单、动作过程或声音说明。

无法获得可信首帧时不要输出猜测 Prompt，应让执行阶段关闭该镜自动生图并报告上游缺口。
