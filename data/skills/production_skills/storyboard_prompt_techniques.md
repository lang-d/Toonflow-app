# 分镜图 Prompt 通用技法

本技法只提供图片 Prompt 生成方法。事实源、写入字段和是否启动图片任务由执行层技能决定。

## 唯一内容来源

图片 Prompt 必须从结构化分镜对象读取，不做创意扩写。核心字段：

- `picture`
- `location`
- `shotSize`
- `cameraAngle`
- `action`
- `characters[].action`
- `characters[].orientation`
- `characters[].spatialPosition`
- `characters[].posture`
- `characters[].expression`
- `characters[].gaze`
- `characters[].handAction`
- `characters[].movement`
- `visibleEmotion`
- `requiredAssets`

`dialogue` 和 `soundEffects` 不直接进入图片画面，除非其中已在结构化视觉字段里表现为可见动作、物件或状态。

## 字段映射

| 结构字段 | Prompt 处理 |
|---|---|
| `picture` | 画面主体，必须完整保留所有可见元素和空间关系。 |
| `location` | 环境锚点，结合参考图和风格技法表达。 |
| `shotSize` | 转成镜头构图词；复合景别取首帧起始景别。 |
| `cameraAngle` | 转成视角词；无明确值时不强行添加。 |
| `action` | 作为整镜动作概述，辅助组织画面。 |
| `characters[].action` | 角色具体动作，必须保留语义。 |
| `characters[].orientation` | 显式写入角色朝向。 |
| `characters[].spatialPosition` | 显式写入角色画面位置。 |
| `visibleEmotion` | 只写可见表演，不写抽象情绪标签。 |
| `requiredAssets` | 生成参考图标注和引用顺序。 |

## 首帧识别

分镜图是视频的首帧参考，不是整段动作摘要。

- 静态瞬间：直接按结构化画面生成。
- 连续动作：取动作开始端或最能识别动作意图的瞬间。
- 镜头运动：取起始景别和起始构图。
- 转场：只保留开场状态，不生成完整转场过程。
- 不把所有动作都改成“即将发生”的预备态；只有连续动作确实需要首帧化时才处理。

## 参考图标注

- 按 `associateAssetsIds` / `requiredAssets.order` 建立参考图顺序。
- Prompt 开头用稳定编号标注参考图，例如“图1为角色A，图2为场景B”。
- 正文中涉及角色、场景、道具时，优先用对应图编号绑定，避免名称歧义。
- 每个被引用资产必须有唯一编号，不遗漏、不重复。
- 衍生资产使用自身名称和类型；不要回退成父资产名称。

## Prompt 结构

推荐使用三段结构：

1. 画面：承载 `picture`、`location`、`shotSize`、角色动作、朝向、空间位置、可见情绪。
2. 视觉状态：只承载导演规划、场景资产状态、结构化分镜明确事实或参考图中已有的视觉状态。
3. 风格：使用风格专属 `director_storyboard` 中的风格锚定和画质约束，篇幅短于画面段。

画面段优先级最高。风格词不得覆盖、替换或挤掉结构化分镜的具体内容。

## 忠实性校验

生成每条 Prompt 后逐项自检：

- `picture` 中所有可见主体、物件、空间层次是否保留。
- `location` 是否与结构化字段一致。
- `shotSize` 是否匹配。
- 角色动作语义是否一致。
- 角色朝向是否来自 `characters[].orientation`。
- 角色位置是否来自 `characters[].spatialPosition`。
- `visibleEmotion` 是否转成可见表演，而非抽象词。
- 是否引入了结构化分镜没有的角色、道具、剧情、场景状态或动作。
- 是否遗漏了 `requiredAssets` 中画面可见的资产。

校验不通过必须修正，不得继续写入。

## 人物连续性

- 同一角色跨分镜保持服装、发型、面部特征和体型一致。
- 同一场景内人物左右关系、前后层次和朝向连续。
- 朝向变化必须对应结构化动作中的转身、转头、走位等可见动作。
- 多角色画面优先写清“谁在画面左/右/前/后、面向谁、注视哪里”。

## 视觉状态与光影色调

- 不凭空新增光线方向、色温、明暗关系、色彩风格。
- 只能来自导演规划、场景资产状态、结构化分镜明确事实或参考图。
- 有参考图时，以参考图中的环境、光线和色彩为准。
- 如果结构化分镜只写普通室内，不得自行扩写成夜景、雨景、逆光、高对比等状态。

## 画质与文字规则

- 主体必须清晰，避免导致糊图的词：失焦、边缘不清、画面不稳定、整体朦胧、低清晰度。
- 禁止画外字幕、水印、标题卡、界面文字。
- 如果画面内自然存在文字道具，只在结构化分镜明确提及时描述其存在，不生成额外文字内容。
- 负向词和画质锁定词按风格专属 `director_storyboard` 执行；若目标图片模型不支持负向词，则不额外输出负向词块。

## 批量处理

- 按分镜 `index` 顺序逐条处理，不跳行、不合并。
- 同一场景连续多镜可以复用场景质感，但动作、景别、朝向、空间位置和可见表演必须逐条独立。
- 参考图编号规则在同一条 Prompt 内稳定；不要跨条强行沿用导致错配。
- 输出内容只用于写入 `prompt` 字段，不附加资产汇总、台词备注、音效备注或校验报告。
