# 分镜表设计通用技法

本 Skill 是景别、对白画面处理、镜头切分和时长估算的唯一通用来源。题材手册只说明该题材哪些事实和状态必须被看见，不预设景别比例或固定秒数。

## 一、先确认动作与信息，再决定切点

先按剧本顺序识别可观察的因果单元：

```text
进入条件 → 触发或判断 → 主体行动 → 可见结果 → 离开状态
```

出现以下实质变化时，考虑新镜头：

- 视觉中心从一名人物、一个物件或一组关系转到另一中心；
- 信息的接收者或判断者改变，观众必须看见其反应；
- 新事实、关键物件状态或动作结果需要独立可读；
- 一个动作在当前构图中无法完整、清楚地呈现；
- 地点、时间、行进方向或人物空间关系发生实质变化；
- 台词、必要停顿和动作明显无法在当前时长内自然完成；
- 当前视频模型一次生成无法容纳完整的连续行动。

以下情况不构成切镜理由：

- 为避免画面单调而机械轮换中景、近景、特写；
- 把同一人物同一连续动作拆成重复的准备、动作和结果；
- 每句台词固定对应一个镜头；
- 插入与当前台词、判断或因果无关的空镜和装饰物；
- 为填满模型最大秒数，把不同视觉中心、不同因果目标或不可连续执行的动作强并。

切点应落在动作和信息的自然边界。若切开后下一镜必须重复上镜动作才能看懂，通常说明切点不成立。

## 二、`shotDescription` 的时间顺序

每镜只写一个连续描述：

```text
最早成立的可见状态 → 触发 → 连续变化 → 结束状态
```

### 最早成立的可见状态

它必须能成为单张分镜图的可信起点，来源只有三种：

1. 剧本或规划直接确认的位置、姿态、持物或正在进行的动作；
2. 首个动作必然推出的前态，例如“放下纸箱”必然说明此前正持有纸箱；
3. 相邻正式镜头已经明确交接、且本镜继续保持的状态。

这种必然前态只允许补足动作成立所必需的信息，不允许补写精确左右站位、朝向、背景布局、未出现物件、后续结果或资产外形。

### 触发、变化和结束

- 触发必须可见或可听，并与主体行动有因果关系。
- 动作写清谁对什么做了什么，以及物件、视线、姿态或表情怎样随行动变化。
- 情绪只转译成当前确有依据的可见表演，不另写情绪标签。
- 结束状态只保留下镜需要继承的人物、物件、位置和关系变化。

### 关键转折的可见表演

只有人物反应本身带来新增叙事信息时，才把内心状态编译为本镜的可见表演：例如接收关键信息后的判断、关系靠近或疏离、克制与失控的临界、态度翻转，或台词所指向的明确反应。

- 按“触发 → 一组必要的可见变化 → 结束状态”写。变化可落在视线、眼周/嘴角、呼吸、手部或姿态中的一两项；选择最能说明当前转折的部分，不枚举全身反应。
- “愤怒、悲伤、紧张、委屈、警觉”等词只能帮助理解，不能单独充当表演事实。应写成有依据的可见结果，例如视线停顿、眼睑收紧、唇角压住、呼吸变浅、手指松开或姿态回避。
- 微表情已经在开拍时成立，就写在最早可见状态；由触发产生，就写在后续连续变化。不要把同一状态同时写成首帧既成事实和触发后的新反应。
- 普通对白、静态说明或没有明确反应依据的场面，不为“增加表演”强行添加表情。

表演示例：

```text
赵成业删去署名后把屏幕转向苏晴。苏晴的视线在名字位置停住，眼睑微微收紧；她压平唇角后抬眼看向赵成业，镜头结束时仍保持克制的直视。
```

动作示例：

```text
苏晴双手扶着尚未封口的纸箱站在工作台旁。门外传来引擎声，她停下手中动作，抬头看向院门；车声靠近后，她松开纸箱，向门口迈出一步。镜头结束时，她停在工作台与院门之间，纸箱仍留在台面。
```

不要在同一描述中设置两个互相竞争的主要行动。确有先后两个独立目标时应重新判断是否拆镜。

## 三、对白中的画面选择

对白不等于持续拍摄说话者。只有出现新信息时才切换画面：

- 台词明确指向一个可见人物、物件或环境事实；
- 听者的判断或关系变化比说话者口型更重要；
- 第三人第一次接收到信息；
- 关键物件状态因台词关联的行动发生变化。

说话者画外续说时，在 `shotDescription` 中自然写明“某人画外继续说”；`dialogue` 只保存本镜实际说出的原文片段。只在原句自然停顿处分段，不改写、不重复，也不要求一句台词固定一镜。

## 四、景别、机位与运镜

景别由“本镜新增信息是什么”决定：

- 空间、路线或多人关系首次成立：选择能读清整体关系的远景或全景；
- 完整动作、物件交接、双人关系：选择能同时保留主体和动作对象的景别；
- 人物判断、细微反应或关键物件状态成为不可替代的新信息：才收紧到近景或特写。

当新信息依赖于屏幕、纸张、照片、镜面、仪表或远端画面等可读视觉载体，同时另一人物的独立反应或行动也要被读清时，本镜只选载体或反应/行动之一作为视觉中心；另一项交给画外声或前后镜承接。只有同一构图确能自然读清两者且不牺牲新增信息时，才允许同镜。

连续使用中景只有在每镜都确实需要同时读取人物与动作对象时才合理。没有新增信息的连续中景、机械景别轮换或无关插入镜都应避免。

若完整动作与细微反应不能在同一构图、同一时长内同时清楚成立，按自然因果切镜，或选择本镜真正新增的信息；不得用泛化中景掩盖表演重点，也不得为表情牺牲动作的完整性。

- `cameraAngle` 只写影响空间理解或剪辑连续的具体拍摄位置与朝向；简单镜头可留空。
- 保持人物行进、视线对象、出入口和物件交接方向。跨侧需有人物移动、沿轴/中性镜头或重新建立空间的依据。
- `cameraMove` 只保留一个必要运动及其可见作用；能用固定镜头清楚表现时不添加运镜。
- 普通硬切不填写 `transitionFromPrevious`；只有时间、地点或方向需要桥接时才写。

## 五、时长与分组

`durationSec` 同时容纳台词、必要停顿、反应和完整动作。平稳清晰普通话可用约 3–4.5 个汉字/秒作宽松参考；低声、犹豫、重音、停顿或明显反应取更慢节奏，只有剧本明确急促时才取更快。

这不是保存公式，也不要求输出计算过程。明显装不下时应在自然语义停顿处拆镜或延长镜头，不能无依据提高语速。

不要只看单镜是否成立；连续镜头若都没有新增事实、动作结果、必要反应或空间/声音交接，只是在重复占用停顿，应合并或缩短。1–2 秒可用于明确的动作落点、视线切换或声音转折，不用于填时长。

一个视频分组应包含模型可连续生成的一段行动，并在真实可切点结束。分组总时长不能超过当前视频模型能力，但不是越接近上限越好。跨组必须让前组结束状态能被后组自然继承。

## 六、声音、资产与连续性

- `dialogue.text` 忠实原文；`voiceTone` 只写该句实际需要的音量、速度、气息、停顿或尾音。
- `soundEffects` 只写有画内来源的声音并按发生顺序排列，不加入 BGM。
- `requiredAssets` 引用本镜可辨识的人物、场景和关键道具，不虚构 ID。
- 已绑定资产的稳定外形不在 `shotDescription` 冗长复述；只写本镜位置、接触和已确认状态变化。
- 相邻镜头逐项承接人物位置、持物、伤病、服装状态、门窗/屏幕状态、车辆方向和持续声音。

## 七、提交前复查

- 是否存在一个连续动作被重复拆写，或多个独立视觉中心被硬塞进一镜；
- `shotDescription` 是否有可信起点、清楚变化和可继承终点；
- 关键反应是否已转成有依据的可见表演，而非只留下抽象情绪词；普通对白是否没有被强行附加微表情；
- 台词、停顿和动作是否能在时长内自然完成；
- 景别是否服务新增信息，反应镜与插入镜是否真的增加信息；
- 相邻镜头是否重复交代、漏掉动作结果或出现无依据跳变；
- 分组是否结束在真实切点，而非机械填满时长。

只修正实际问题，不为了字段更满添加无用信息。
