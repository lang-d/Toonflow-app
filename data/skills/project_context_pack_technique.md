# 项目制作参考包写法

参考包不是摘要文章，而是后续导演规划的项目级软参考。

## 固定结构

正文必须使用以下 Markdown 二级标题，并按此顺序输出。将“资产复用参考”放在前部，使资产基础设定可以在有限上下文中优先取得稳定锚点：

## 项目硬事实
## 资产复用参考
## 连续性锚点
## 视觉与导演参考
## 配乐参考
## 缺资料与不确定项

## 写法要求

- 每条尽量短，优先写可执行约束。
- 不编造资料中没有的人名、地点、组织、世界规则和角色关系。
- 不确定的内容明确写“不确定”“暂无明确资料”或“待补充”。
- 不复述原文长段，不输出泛泛而谈的宣传文案。
- “资产复用参考”不是一句“复用同一资产”的泛泛说明；按资料中实际出现的资产写紧凑事实卡。资产名称须与资料一致，优先保留可跨集复用的硬锚点。
- 角色事实卡：身份和关系边界、年龄感、面部/发型/体态锚点、默认服装与长期配饰、不可变外形特征。若资料明确声音设计，再写“声音/台词表现”：声线年龄感、音区倾向、音色质地、咬字和语速、情绪表达习惯、方言/口音或语言边界；未明确则写“待设定”，不得由性别、年龄、职业或地域推断。
- 场景事实卡：固定用途、布局、入口出口、长期环境锚点、常设材料和陈设；排除某集临时人物位置、天气、屏幕内容、证据和剧情摆放。
- 道具事实卡：用途、轮廓、尺寸关系、结构、材质、固定标识、长期磨损或归属；排除具体聊天、金额、录音内容、屏幕文字等临时信息内容。
- 角色声音/音色是制作参考，不等同于 TTS 供应商、音色 ID、真人模仿、克隆参数或音频文件；这些内容不得进入参考包。
- 角色、场景、道具都应写清如何保持一致和避免重复创建，但不得把视觉手册的表现方法反向写成资产事实。
- 视觉与导演参考只写项目级方向，不替代单集导演规划。
- 配乐参考只写后期音乐方向；画内环境音可作为声音方向，BGM 不应写成视频模型提示词要求。

## 禁止

- 禁止写成分镜表、镜头清单、导演规划或视频提示词。
- 禁止使用大量空泛词堆叠，例如“高级感、电影感、极致细节、氛围拉满”等。
- 禁止把用户本轮指令以外的推断写成确定结论。
- 禁止用“年轻女声”“沉稳男声”“乡音”等刻板标签替代资料支持的角色声音事实。
