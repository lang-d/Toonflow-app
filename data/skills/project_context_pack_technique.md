# 项目制作参考包写法

参考包不是摘要文章，而是后续导演规划的项目级软参考。

## 固定结构

正文必须使用以下 Markdown 二级标题：

## 项目硬事实
## 连续性锚点
## 资产复用参考
## 视觉与导演参考
## 配乐参考
## 缺资料与不确定项

## 写法要求

- 每条尽量短，优先写可执行约束。
- 不编造资料中没有的人名、地点、组织、世界规则和角色关系。
- 不确定的内容明确写“不确定”“暂无明确资料”或“待补充”。
- 不复述原文长段，不输出泛泛而谈的宣传文案。
- 角色、场景、道具优先写“如何保持一致”和“如何避免重复创建”。
- 视觉与导演参考只写项目级方向，不替代单集导演规划。
- 配乐参考只写后期音乐方向；画内环境音可作为声音方向，BGM 不应写成视频模型提示词要求。

## 禁止

- 禁止写成分镜表、镜头清单、导演规划或视频提示词。
- 禁止使用大量空泛词堆叠，例如“高级感、电影感、极致细节、氛围拉满”等。
- 禁止把用户本轮指令以外的推断写成确定结论。
