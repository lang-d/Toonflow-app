# Story Script Writing

Use this when the user asks for full script text.

Write with:
- clear scene headings
- action lines that can be adapted into storyboard and video prompts
- character dialogue
- concise emotional beats
- production-friendly locations and actions

Avoid novel-like exposition. Show conflict through action and dialogue.
If output is intended for production, persist it as a `script` artifact.
