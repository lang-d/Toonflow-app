# Story Concept Brainstorm

Use this when the user has a vague idea or no clear direction.

Output practical creative options, not a final script. Each option should include:
- title
- genre
- logline
- core hook
- main character
- conflict
- why it can work for short video or Toonflow production
- risks or questions

Prefer 3-5 directions. If the user chooses one, help turn it into a story bible or outline.
