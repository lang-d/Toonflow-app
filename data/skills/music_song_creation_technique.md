# Music Song Creation Technique

Use for explicitly requested theme, opening, ending, or insert songs.

First define the song's narrative job, listener perspective, recurring hook, vocal identity, language, and reuse scope. A song is not justified merely because a project has opening or ending credits.

Structure should create one memorable center:
- verse establishes perspective without dumping plot
- pre-chorus raises pressure only when useful
- chorus states the emotional thesis in singable language
- bridge changes meaning or perspective rather than adding louder repetition
- intro/outro length follows the intended use

Narrative editions keep the same work identity while changing arrangement, harmony, density, register, vocal presence, or cadence. Create a new work only when melody, hook, perspective, and dramatic identity are substantially different.

For stage evolution, specify what remains invariant and what changes. Do not plan or generate every future edition before its narrative need is clear.
