# 分镜表叙事手法 · 荒岛求生 / 孤岛困境 · 技法参考

## 使用边界

只把已确认的剧本事实和导演规划拆成镜头条件。分镜表负责景别、机位、时长、动作轴线、信息先后和转场，不重新发明遇险原因、资源、岛屿区域、人物能力、救援结果或视觉风格 Prompt。未确认的资源、路线、伤病、潮汐或天气应保留待确认，不以镜头说明补齐。

## 一、以状态写回为拆镜单位

每组行动按“**信息建立 → 人物评估 → 动作准备 → 接触阻力 → 结果确认 → 状态写回**”寻找拆镜点。不是六步各占一个镜头，而是任何省略都不能破坏因果：观众必须能看清人物依据什么条件行动、如何接触对象或地形、行动后哪个人、物、路线或风险发生了变化。

- 信息建立先给出可辨认的物、地标、天气征兆或同伴状态；不要先用人物反应替代信息本身。
- 人物评估以视线、停顿、手部检查、互看、比对或已确认对话组织，不添加人物心声。动作准备交代已确认的工具或徒手方式、受力位置、协作站位和预定退路。
- 接触阻力保持行动起点、方向、对象和受力关系清楚；跨越湿沙、礁石、林地、洞口或营地时，给出必要的落脚、入口或转向信息。
- 结果确认拍到行动是否完成以及即时代价；状态写回则明确获得、消耗、转移、损坏、遗失、不可用或未知中的哪一种变化，并让下一镜继承。

任何资源、伤病或携带状态变化都至少需要三个可读信息：**变化前条件、造成变化的关键动作、变化后状态**。三者可以在一个连续镜头内完成，也可以拆开；不得用切镜、遮挡或台词跳过中间因果。若结果仍未知，状态写回应是“未确认”，不能偷换成成功或失败。

### 已确认行动的通用拆解

以下只是动作语法，只有剧本或规划已经包含相应行动时才使用：

- 寻找或观察：建立搜索范围与观察者位置 → 给出视线或扫描路径 → 呈现可见依据 → 确认发现或仍未知。不得凭反应镜头创造目标物。
- 采集或取用：先见来源和原状态 → 见接触、取出或装入 → 确认来源与容器两端的变化。不得跳过数量或归属变化。
- 搬运或转移：交代起点、负重方式、协作站位与路线 → 呈现阻力或停顿 → 在终点确认人员、物件和体力状态。
- 搭建或修补：交代已有材料与待处理对象 → 呈现关键连接、固定或测试动作 → 确认稳定、未完成或损坏状态。不得补出材料和功能。
- 照料：交代伤病事实、照料者位置和已有物品 → 呈现可见照料动作 → 确认人物可行动程度是否按事实改变。不得把照料拍成无依据治愈。
- 求援或联络：交代已有装置、信号条件或观察方向 → 呈现发送或等待动作 → 只确认已发出、未发出、收到反馈或结果未知，不自动获得救援。

## 二、地理、潮汐与人物轴线

先按规划记录本场所在区域、人物进入方向、可见出口、前进目标和退路。海岸、营地、林地、淡水点、礁石、洞穴等只有在事实已确认时使用；区域之间的转场要给出地标、方向或时间依据。

- 海岸镜头保持海在画面哪一侧、潮线相对人物的位置、人物的来路和退路；潮水变化只按已确认的时段或剧情信息表现。
- 营地回归镜头复核遮蔽区、储物点、休息位置和已确认损耗，令营地成为资源与关系的连续性锚点。
- 同行者移动时保持前进方向与视线方向；分队、交叉、折返或越过地标前，用建立镜头、过肩镜头或明确的运动方向重建轴线。
- 伤病、负重、潮湿或疲劳状态必须在镜头衔接中连续；没有确认就不要增加绷带、湿衣、晒伤、工具或补给。

### 条件化区域覆盖

- 海岸：建立海在画面哪一侧、潮线与人物的距离、沿岸前进方向、可见地标和退路；海面远景不能替代脚下通行条件。
- 潮间带：先见潮线、裸露面和返回边界，再进入行动中景；若潮位变化已确认，用同一地标或落脚面比较变化，不凭颜色滤镜表达涨落。
- 营地：建立出入口、休息或储放位置和已确认设施的相对关系；返回时用相同锚点核对人、物和未完成事项。
- 林地或林缘：交代进入边界、植被遮挡、可回望地标与声源遮蔽；人物转向或离开视线前保留最后可见位置。
- 礁石或岩面：交代高低差、可落脚面、受力方向、遮挡和退路；近景只能确认关键接触，不能隐藏人物如何跨越。
- 洞穴或洞口：只有事实确认时使用；先建立洞口朝向、内外明暗、入口与退路，再进入内部。不得从“岛屿题材”推导洞穴存在。

分队、折返、失散、会合、潮位变化或跨区域转场发生后，只要原有海陆方向、机位半区或人物相对位置不足以继续理解，就必须重新建立方向。可使用地标同框、人物越过轴线的连续运动、回望来路、出入口反打或新的全景；不能靠对白宣称“回来了”代替空间重建。

## 三、景别、机位与时长

环境建立镜头用于交代海陆尺度、区域连接、可通行范围和退路；行动中景维持人物与地形、同伴和资源的关系；物件或伤病状态近景只在确认手部动作、余量、损坏、落脚或伤病变化时使用；反应镜头负责呈现人物接收了什么信息和关系如何响应。四类镜头各有职责，连续特写不能跳过生存过程，空泛大全景也不能替代关键动作。

- 资源、信号、路线或天气信息先有可读镜头，再给反应镜头；避免只用特写把观众困在人物情绪中。
- 危险接近时保持逃生地理：人物向哪里退、谁落后、障碍在哪一侧、下一处安全点是否已确认。
- 长镜头适用于等待、观察、分工协作或环境压迫；短镜头用于明确的动作节点。不要用碎切伪造复杂求生或跳过行动成本。
- 转场跟随已确认的时间、天气、地点或状态改变；日夜、风雨、营地损坏与资源余量不能靠无依据的蒙太奇跳变。

## 四、声音与反应链

在分镜表中标注重要现场声源与其先后：浪声、风声、植被摩擦、脚步、水滴、容器、呼吸、远近呼喊等。说明声源相对人物的方向、距离及是否被风、植被、岩面或洞口遮蔽；声音先形成可听依据，再引导人物反应。若声源不明，镜头仍须保留人物所在位置与可探索范围，不能以跳切制造地理混乱，也不能用音乐代替危险或地理信息。

多人场面中，反应链遵循“行动者 → 受影响者 → 观察者或回应者”。分配资源、扶助伤者、路线争议和救援等待均应让关键人物的站位、视线和物件归属可读，不重写规划中的关系判断。

## 五、荒岛分镜检查

- 每个行动段是否能看见发现、评估、尝试和结果中的必要信息？
- 地理是否保持海陆方向、营地锚点、入口出口、潮汐和退路连续？
- 人物、资源、携带物和伤病是否在每次切换后仍符合上一镜结果？
- 景别、机位、时长和声音是否服务于行动因果，而不是输出视觉风格描述？
- 是否避免任何未确认的求生工具、野生动物、救援、灾害或结局？

## 禁止项

- 禁止重新编写剧情、人物动机或救援结果。
- 禁止输出视觉风格 Prompt、图像生成参数、工具名、运行流程或持久化流程。
- 禁止加载或引用废弃的视觉分镜 Skill。
