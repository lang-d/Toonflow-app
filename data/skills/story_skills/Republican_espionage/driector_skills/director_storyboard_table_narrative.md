# 民国谍战 · 分镜表叙事技法

## 使用边界

只拆已确认的监视、传递和行动，不添加年代器物、武器、组织、密码或视觉风格。

## 监视与跟踪拆镜

按“目标位置 → 观察者位置 → 可见/不可见条件 → 目标移动 → 观察者应对 → 距离或暴露变化”拆镜。始终说明遮挡物、街道方向、入口出口和双方视线；主观镜只能包含该人物实际可见信息。

跟踪跨街道、车站、楼层或交通工具时保持前进方向、相对距离和最后可见位置。甩脱只有拍清遮挡、转向、换位或时间差才成立，不能靠跳切让人物消失。

- 目标进入遮挡前保留其速度、方向和可能出口；重新出现时须与遮挡持续时间和路线相符。
- 观察者切换位置时，先建立其移动或新的观察条件，不能让主观镜跨越不可能视距。
- 目标开始反监视时，拍清触发怀疑的可见事实、试探动作和观察者应对，而不是突然让双方互知。

## 接头与情报交接

接头按“双方到达 → 身份确认 → 载体原归属 → 交接动作 → 新归属 → 是否被观察 → 分离路线”组织。可在连续镜头中完成，但关键载体不能在遮挡后凭空换手。

身份暴露节点先给造成怀疑的可见事实，再给判断者反应和行动选择；服饰、孤立局部画面和音乐不能单独证明身份。

情报载体被遮挡交接时，至少在遮挡前后确认手部位置、原归属和新归属；无法确认内容时只记录载体变化。第三者是否目击要由其位置、视线和遮挡条件成立。

## 空间、交火与年代连续

街道、车站、住宅和办公空间先建立地标、门窗、楼梯、交通方向和安全出口。若剧本确认交火，保持敌我方向、掩体、弹道风险、武器归属和人员状态；没有确认不增加枪械。

交火前先重建人员与交通方向，确认掩体是否真实存在且能阻挡什么；交火后确认人员位置、武器归属、伤势和撤离路线。不能用烟雾、碎切或慢动作隐藏空间关系。

年代器物在镜头间保持结构、使用方式和位置，不用现代界面、现代交通或跨年代声音补信息。

## 可见信息与声音

监视关系首次成立时须看清双方位置、路线、距离与遮挡；接近、跟随与交接须保持人物、载体和空间关系连续；身份细节、载体或手部动作只有改变判断时才单独强调；人物反应必须体现怀疑程度或下一步行动变化。具体景别由通用分镜技法依据本镜新增信息决定。声源写明距离、方向、遮挡和听见者。

## 检查与禁止

- 监视者与目标的距离、遮挡和知情状态是否连续？
- 情报载体是否拍清原归属、交接和新归属？
- 身份暴露是否先有可见触发，再有判断与行动后果？
- 跨街道、车站、楼层或交通工具时是否保留最后可见位置和前进方向？
- 景别与时长是否由通用分镜技法按信息变化和行动可容纳性决定，没有题材预设？
- 禁止跳切完成甩脱、用滤镜证明年代、用音乐证明背叛。
