# 社会现实强情绪短剧 · 分镜表叙事技法

## 分镜表定位

- 分镜表要把导演规划里的压力、关系和后果拆成可拍摄的单镜事实，不复述完整心理分析。
- 按压力变化、关系转向、事实确认和行动决定拆镜，不按每句台词机械切镜。
- 一组分镜只承载一个连续事件目标；公开与私下、解释与行动、等待与执行发生转换时应重新分组。
- 本手册只提供社会现实强情绪短剧的叙事拆镜方法：为什么切、切给谁、切到什么现实后果。
- 本手册不定义通用机位语法、字段契约、资产引用规则、时长公式、图片 prompt 或视觉生产参数；这些均服从 `storyboard_table_techniques` 和执行层工具契约。

## 拆镜触发条件

遇到以下变化时，应考虑新建镜头或新建分镜组：

| 触发 | 拆镜目的 |
|---|---|
| 压力变化 | 压力从口头争执变成账目、流程、照护、交付或公开评价时，给出可见落点。 |
| 关系转向 | 请求变摊牌、忍让变留痕、熟人变旁观、同盟变切割时，记录距离和站位变化。 |
| 事实确认 | 通知、账单、聊天记录、合同、录音、工资表等信息改变局面时，拆出物件与反应。 |
| 行动决定 | 人物准备签字、离开、归还、拒绝、展示、整理、关门、打电话时，给动作节点。 |
| 公共暴露 | 私事被邻里、同事、群聊、平台或组织看见时，保留旁观者沉默和回避。 |
| 空间后果 | 空位、关门、物件被拿走、桌面被清空、队伍停住、店面停摆等成为结尾落点时，单独成镜。 |

## 对话场规则

- 对话场不得只做正反打流水账；至少保留说话者、听者反应和关系空间。
- 听者反应不是装饰，必须承担信息：停顿、吞咽、眼神避开、手指攥紧、身体后退、动作变稳。
- 第三方或旁观者存在时，不必大量给围观镜头；一个停住、低头、抬手机又放下、声音压低的反应即可形成公共压力。
- 关键台词后优先切听者，而不是继续跟说话者解释。
- 能用同一镜头同时交代说话者和听者反应时，不拆成两个机械镜头。

## 题材化镜头偏好

- 同一轴线下的机位选择要服务压力关系：谁被逼问、谁在回避、谁被迫作决定，比谁说话更重要。
- 关键台词后优先寻找听者的可见反应、第三方的沉默或空间阻隔，而不是继续给说话者解释。
- 证据、账单、通知、聊天记录等事实出现后，应有一个人物反应或现实动作承接，让观众看到事实造成的后果。
- 插镜优先给手部、物件、门框、桌面、空位、屏幕亮起/熄灭等现实压力出口；不使用无功能的氛围空镜。
- 结尾镜头优先落到决定、通知、空位、关门、归还、表情或物件状态变化，避免用长台词解释钩子。

## 证据镜头规则

- 证据特写只在改变局面时出现；不能为了制造爽点新增证据或反复读屏幕。
- 复杂信息拆成两个镜头：物件特写负责“事实可读”，人物反应负责“事实造成后果”。
- 屏幕、合同、账单、工资表、通知等必须短而可读；只展示当前剧情必须理解的字段。
- 证据第一次出现可以是留痕或整理，第二次才展示用途；不要让所有证据在同一镜头里一次性解决冲突。
- 证据道具和屏幕内容必须来自剧本、导演规划或已存在资产事实；本题材手册只决定其叙事功能，不新增事实。

## 现实压力镜头方法

| 方法 | 使用条件 | 分镜表达 |
|---|---|---|
| 近景压迫 | 人物被迫回应、被公开评价、被堵在流程里 | 景别收紧到面部、肩背、手部或桌面边缘，表现呼吸和控制。 |
| 手部动作 | 人物从解释转向行动 | 压纸、攥手机、整理材料、推回物件、收起账单、握住门把。 |
| 停顿镜头 | 新事实落下、体面话失效、旁观者沉默 | 2-4 秒内只保留表情、呼吸、环境音或动作停住。 |
| 空间阻隔 | 关系无法直接靠近或责任被隔开 | 门框、桌面、柜台、玻璃、椅背、前景人物形成阻隔，但不改变既有场景资产结构。 |
| 旁观者沉默 | 私人冲突被公开看见 | 给旁人回避视线、动作停住、声音压低、手机抬起又放下，而不是夸张围观。 |
| 空间后果 | 行动已经产生现实变化 | 空位、关门、撤走、归还、清空、重新排队、停摆、灯牌关闭等成为视觉落点。 |

## 节奏与时长倾向

- 开场镜头尽快建立压力源、责任关系或正在发生的后果。
- 台词密集段要给表演停顿留时长，不能只按字数填满镜头。
- 关键沉默通常 2-4 秒；超过这个范围必须有新的动作、信息或空间变化支撑。
- 证据特写短而可读；若信息复杂，拆为物件特写和人物反应，不拉长读屏时间。
- 公共羞辱或关系破裂时，给旁观者反应或空间后果，不用煽情慢动作。
- 结尾钩子不拖长解释，优先落到决定、通知、空位、关门、归还、表情或物件状态变化。

## 视觉钩子与连载落点

- 每集结尾至少有一个现实后果可见：东西被放下、门被关上、桌面被清空、通知弹出、某人离开位置、某人终于站稳。
- 钩子来自已经建立的事实，不能新增制度惩罚、围观爆发、突然证据或外部救援。
- 结尾镜头要让观众知道下一集的压力方向，而不是只靠台词宣布“还有更大的事”。
- 单集爽点服务关系位移，不得让人物底色和项目主题突然失真。

## 声音

- `soundEffects` 只写画内环境声和动作声，例如提示音、纸张、门锁、脚步、打印机、餐具、键盘、工具声。
- 关键事实确认时可以减少声源或留下短暂停顿，但不得把 BGM、乐器和配乐情绪写入 `soundEffects`。
- 环境音要服务空间：楼道回声、柜台叫号、餐具停住、键盘停下、门锁合上，都可以成为关系变化。
- BGM 只作为后期边界：克制、后置、避免过度煽情；最终音乐由独立配乐阶段处理。

## 禁止项

- 不用过量慢动作、英雄仰拍、犯罪片式窥视、悬疑大片式反转制造虚假强度。
- 不为制造爽点新增围观、录音、证据、直播、处罚、法律结果或制度介入。
- 不把心理解释直接写进 `visibleEmotion`；只写画面中可见的脸、眼、手、肩背、呼吸、站姿和语气出口。
- 不输出视觉生产参数或生成表达。
- 不复述角色稳定外观、场景固定装修或道具常态设定；已由资产锚定的内容只通过当前镜头动作、站位和反应体现。
