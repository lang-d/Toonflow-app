# 分镜表叙事手法 · 现代种田经营 · 技法参考

## 一、分镜定位与职责边界

只把已确认的剧本事实和导演规划转成镜头条件。分镜表负责拆镜点、景别、机位、动作轴线、信息先后、时长依据、声音和转场，不重新决定：

- 经营方案、生产步骤和农业技术；
- 商品状态、品质、批次、数量和价格；
- 订单、客户、付款、交付或售后结果；
- 人物能力、关系、路线、工具和空间；
- 视觉风格或图片 Prompt。

事实缺失时保留待确认。不能靠镜头说明、反应特写或蒙太奇补齐经营事实。

## 二、拆镜触发矩阵

拆镜以信息和状态变化为依据，不按每句台词、每个手部动作机械切镜。

| 触发 | 需要观众看清 | 常用承接 |
|---|---|---|
| 条件改变 | 天气、时间、空间、工具或人员怎样改变可行动范围 | 环境或关系镜建立新条件，再进入动作 |
| 信息确认 | 谁看到、收到、核验或确认了什么 | 信息载体与人物判断形成前后关系 |
| 商品状态改变 | 变化前状态、关键动作、变化后状态 | 物件可读镜头承接人物操作 |
| 持有人改变 | 谁递出、谁接收、谁保管、放到哪里 | 同框递交或动作匹配保持方向 |
| 承诺进入新阶段 | 提出、收到、确认、执行、完成或未知 | 人物、记录和后续行动共同证明 |
| 路线改变 | 起点、去向、携带物和改变原因 | 方向镜或地标重建空间 |
| 关系位移 | 决定、执行、核验、承担后果的人发生变化 | 关系镜、物件归属和反应共同呈现 |
| 喜剧反应对象变化 | 谁先看见、谁受影响、谁收尾 | 按信息传播顺序切换，不补围观者 |

同一连续镜头能够完整呈现条件、动作和结果时不必拆开；任何省略会导致商品、人员、承诺或路线突然变化时必须补足。

## 三、经营行动镜头链

按以下链条寻找必要镜头：

`条件建立 → 人物核验 → 准备或分工 → 关键操作 → 交接 → 结果确认 → 下一场条件`

### 条件建立

先让观众知道区域、对象、当前状态、工作位、路线或承诺，再给人物反应。不能只拍紧张表情，让观众猜问题是什么。

### 人物核验

通过视线、检查、比对、递交、已确认对话或记录呈现。核验镜头只能确认画面和事实支持的内容，不能产生新的专业结论。

### 准备与分工

交代谁取得什么、站在哪里、面对什么、从何处开始、走哪条已知路线。多人协作要能看清工作半区、递交方向和等待关系。

### 关键操作

保留改变状态所必需的接触、受力、开合、装入、取出、移动或确认节点。不必穷举操作步骤，但不能用切镜、遮挡、字幕或台词跳过因果。

### 交接与结果

拍清谁持有、物件到哪里、承诺推进到哪一步、即时限制是什么。结果未知时明确仍待确认，不偷换为成功或失败。

任何生产、商品、承诺或资源变化至少包含：**变化前条件、造成变化的关键动作、变化后状态**。三者可在一个镜头内完成。

## 四、条件化行动拆解

以下只是已有行动的镜头语法，剧本和规划未出现时不得补入。

| 行动 | 必须建立 | 关键可见点 | 结果确认 |
|---|---|---|---|
| 观察或检查 | 范围、人物位置、对象原状态 | 视线、接触、比对或记录 | 发现、排除、仍未知或进入下一步 |
| 采收或制作 | 来源、对象、容器或工作位 | 接触、受力、分离、组合或完成节点 | 对象、容器和工作位的新状态 |
| 分级或包装 | 待处理物、已确认标准、容器 | 选择、分出、装入、封合 | 归属、去向和待处理/已处理状态 |
| 搬运或短驳 | 起点、负重、协作站位、路线 | 抓握、抬起、转向、通过、放下 | 人物、物件、容器和终点状态 |
| 交接或发运 | 双方、物件归属、交接位置 | 核验、递交、装载、签收事实 | 持有人与承诺当前阶段 |
| 沟通、退回或暂停 | 触发条件、沟通对象、当前状态 | 已确认的联系、决定或返还动作 | 只确认已通知、已退回、已暂停或未知 |
| 恢复或返工 | 先前停止条件、可恢复范围 | 检查、清理、重新分工或操作 | 已恢复范围和仍未解决事项 |

## 五、商品、订单与证据镜头

标签、订单、消息、票据、屏幕和记录只有在改变人物判断或行动时才值得单独呈现。

- 物件镜头负责让事实可读：名称、归属、状态、位置或已确认内容；
- 人物镜头负责判断、选择、责任和后果；
- 信息载体与人物必须建立归属，不能出现无人持有、来源不明的屏幕或票据；
- 可读文字只呈现剧本或资产已确认内容，不自行编造数字、品牌和条款；
- 同一信息不在台词、屏幕和特写中重复解释，除非人物的复核本身改变关系或行动。

必须严格区分：

- 消息发出与对方收到；
- 对方收到与完成确认；
- 递出商品与对方验收；
- 车辆离开与商品送达；
- 验收完成与付款结算。

镜头只能证明它实际拍到的阶段。

## 六、空间、轴线与连续性

### 工作空间

按规划建立区域、入口、出口、工作半区、物件起止位置、递交方向和返回路线。

- 生产区：建立可操作面、边界、人物来路和对象位置；
- 检查/包装位：建立待处理物、已处理物、容器和台面方向；
- 储放点：保持堆放、归属、可用空间和未完成事项；
- 院坝、道路或交接点：交代来向、去向、车辆与人物可通行面；
- 跨区域：用地标、运动方向、携带物或时间依据建立连接。

### 轴线

- **工作轴线**：人物与操作对象的关系，不因反打改变左右手和受力方向；
- **交接轴线**：递出者、接收者和物件移动方向，交接后持有人明确；
- **道路轴线**：车辆、人物和商品从何处来、向何处去；
- **关系轴线**：决定者、执行者和核验者的站位变化服务权责位移；
- **入口出口轴线**：离开、返回、等待和堵塞的方向保持可追踪。

跨区域、折返、分队、交接、天气改变或工作位重组后，原有左右关系不足以继续理解时，用地标同框、连续运动、回望来路、入口反打或建立镜头重建方向。

### 连续账本

逐镜核对：

- 商品批次、状态和数量事实；
- 容器开合、装载与所在位置；
- 工具和记录的持有人；
- 人物站位、手上物件和移动方向；
- 订单或承诺所处阶段；
- 天气、地面、照明和可通行条件。

不得因切镜让商品、容器、人物和承诺突然跳到下一状态。

## 七、题材化景别与时长

| 景别/镜头功能 | 适用任务 | 使用边界 |
|---|---|---|
| 环境或关系镜 | 建立工作条件、路线、多人分工和空间限制 | 不以漂亮风景替代可执行空间 |
| 中景 | 承担完整劳动、受力、递交和多人协作 | 优先保留动作因果和人物关系 |
| 近景 | 确认手部、材料、标签、开合、接触和状态变化 | 只拍关键事实，不连续堆叠细节 |
| 人物近景 | 判断、拒绝、承担、关系位移和现实后果 | 先有可理解的触发事实 |
| 连续跟随 | 搬运、短驳或跨工作位移动 | 只在路线与携带物需要持续可见时使用 |
| 建立/重建镜头 | 首次进入或方向关系改变 | 已经清楚时不重复定场 |

时长由以下因素决定：

- 动作是否完整；
- 信息是否可读；
- 多人协作是否能分辨；
- 受力、开合和交接是否需要连续呈现；
- 反应是否改变判断或关系；
- 转场是否需要重新建立空间。

## 八、轻喜剧反应链与声音

只有规划已经存在喜剧条件时，按：

`行动者 → 受影响者 → 先发现者 → 负责核验或收尾者`

- 先建立正常任务和物件位置；
- 偏差发生时保持动作与物理后果清楚；
- 反应顺序服从人物视野和信息传播，不强制每人都切近景；
- 笑点后保留整理、归还、清洁、复核或继续工作的现实收尾；
- 不用甩镜、急推、夸张音效、慢动作和突然加入旁观者制造笑点；
- 儿童与动物的镜头不替代成年人做经营和安全判断。

声音只写画内或现场可成立的声源：

- 操作声证明接触、开合、包装和受力；
- 脚步、车辆和空间混响帮助判断距离与路线；
- 通信声必须与设备和持有人对应；
- 遮挡和声量变化可提示人物接近、离开或跨区；
- 不把配乐写入题材分镜规则，不用音效替代状态变化。

## 九、分镜检查

- 是否只拆已确认规划，没有重新发明经营事实？
- 每个拆镜点是否来自条件、信息、商品、持有人、承诺、路线或关系变化？
- 变化前条件、关键动作和变化后状态是否可见？
- 消息、交接、发运、送达、验收和结算是否被正确区分？
- 商品批次、容器、持有人、工作位、路线和天气是否连续？
- 近景是否只承担关键事实，而没有跳过完整劳动过程？
- 喜剧是否保持信息传播顺序，并在笑点后回到现实任务？

## 禁止项

- 禁止补写作物、产量、标准、订单、客户、技术、工具、路线和经营结果；
- 禁止按台词轮次机械切换，也不以预设时长和镜头数量替代现场动作判断；
- 禁止以空镜、蒙太奇、字幕、屏幕或旁白替代经营因果；
- 本手册的输出止于镜头拆解、连续性、声音和转场方法。
