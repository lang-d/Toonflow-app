# 分镜表叙事手法 · 科幻末世 · 技法参考

## 应用边界

只拆剧本确认的世界规则、技术、资源、环境、伤病和人物选择，不补末日原因、设备功能、怪物、灾害或生存结果。景别和时长只按通用分镜技法决定。

## 规则与资源状态

记录当前可用资源、设备状态、限制条件、持有人和变化原因。资源发现、消耗、转移、损坏或不可用必须有可见动作与结果；界面、广播和台词不能自动证明设备已经完成操作。

## 生存行动链

```text
环境条件 → 当前目标 → 检查/准备 → 可见行动 → 阻力 → 代价 → 新状态
```

每次切镜服务条件、行动主体、资源状态、地理或结果改变。危机节奏不能跳过准备、接触和结果，人性选择也不能只停留在表情和宣言。

## 技术信息可读性

- 设备、屏幕、信号和权限按已确认功能呈现；
- 信息载体只显示剧本已有内容，不补读数、警报或高科技界面；
- 台词进行时可以展示正在被判断的设备状态、受影响的人或环境结果；
- 物件状态与人物反应分工清楚，不能用闪烁界面替代行动因果。

## 环境地理与群体行动

建立安全区、危险来源、目标、路线与退路。移动、探索、撤离、分队和会合后保持方向与资源归属；环境规模服务行动条件，不以废墟或奇观展示替代路线。

## 声音与连续性

声音来自环境、设备、通信、脚步、呼吸和接触，并注明人物是否可听。伤病、防护、资源数量、设备状态、入口出口与队伍位置跨镜连续。

## 检查

- 世界规则是否通过具体限制与结果成立；
- 资源和设备变化是否有行动链；
- 对白插入画面是否增加技术或生存信息；
- 危机之后是否保留代价与新状态；
- 是否没有固定危机碎切、荒原空镜秒数或景别公式。
