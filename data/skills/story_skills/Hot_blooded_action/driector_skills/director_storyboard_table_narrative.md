# 分镜表叙事手法 · 热血动作 · 技法参考

## 应用边界

只拆已确认的目标、能力、动作、地形、协作、伤势和结果，不增加招式、武器、爆炸或胜负。景别和时长只按通用分镜技法及动作完整性决定。

## 动作因果链

```text
目标与距离 → 起势/准备 → 接近 → 接触 → 受力或反制 → 结果确认 → 恢复/下一目标
```

关键接触不能只拍挥动和结果，必须让攻击方向、受力对象、落脚面及结果可读。动作连续可理解时保持同镜；目标、攻防权、方向或结果改变时才考虑切镜。

## 方向与空间

- 建立主要攻防方向、双方距离、可行动面和障碍；
- 换位、绕行、腾跃、跌倒或器械脱手后，用连续运动、共同地标或重新建立的空间关系承接；
- 群体动作按局部协作或对抗组维护，不把所有人剪成无方向碎片；
- 伙伴支援必须看清谁发现、如何接近、做了什么以及改变了什么。

## 冲击、反应与恢复

冲击结果落到重心、接触点、物件、位置或伤势变化。反应镜用于确认人物获得的新判断，不能代替动作结果；恢复段说明谁重新站稳、失去什么、改变目标或承担代价，不让状态在切镜后自动复原。

## 对白与行动

交锋中的台词服从呼吸与动作条件。说话仍在继续时，可呈现对手判断、伙伴接收信息、关键物件或动作准备，但必须提供新的战术或关系信息。长台词明显影响动作完成时按自然停顿拆分或调整时长，不用无依据的高速说话。

## 声音与连续性

声音对应脚步、接触、器械、呼吸、环境和空间反射。维护人物位置、攻防方向、伤势、器械持有人、弹药/损坏状态及环境破坏结果。

## 检查

- 每次接触是否具有方向、对象、受力和结果；
- 反制与伙伴协作是否有可见行动链；
- 切镜后距离、伤势和器械状态是否连续；
- 对白插入画面是否增加战术或关系信息；
- 是否没有动作题材预设景别、固定秒数或镜头配额。
