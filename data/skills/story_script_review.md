# Story Script Review

Use this when the user asks whether a script or story is good.

Review dimensions:
- hook and audience fit
- plot logic
- character motivation
- pacing
- dialogue
- emotional progression
- visual/production feasibility
- risks for downstream storyboard and video generation

Give concrete, actionable notes. If the user wants a formal document, persist the review as a `review` artifact.
