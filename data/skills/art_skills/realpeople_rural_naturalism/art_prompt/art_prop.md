# 真人乡土自然写实 · 道具基础资产

## 职责与方法

`assetFoundation` 读取名称、生活/生产用途、地域、尺寸、轮廓、结构、材料、制造方式、标识和基础状态；`visualDesignRationale` 负责识别、握持受力与可制造性。表现确认木、竹、藤、金属、陶瓷、玻璃、塑料、织物或复合材料，不默认农具、筐篮、粮食、非遗工艺和陈旧磨损。

## 类型专属设计方法

- 木、竹、藤分别说明纹理方向、劈切/编结、榫接、钉接或绑扎中事实支持的连接；不因地域默认手工艺或非遗技法。
- 金属表现铸造、冲压、锻制、折边、铆接或焊接中实际结构；陶瓷表现壁厚、口沿、足部与釉面，玻璃表现边缘和装配。
- 塑料说明成型、壁厚、卡扣与接缝，织物说明裁片、缝线、包边与受力；新旧材料可以共存但需有资产依据。
- 先确定用途、尺度、重心、握持/承重/接触区，再决定轮廓与连接，不能为乡土感牺牲可用性。
- 正侧背/底部与结构特写保持轮廓、开口、接缝、颜色和标识一致，基础状态不自动磨损做旧。

## 提示词模板（编译顺序）

```text
真人乡土自然写实道具基础设定图，prop design sheet；稳定事实：{名称、用途、地域、尺寸、轮廓、结构、材料、制造方式、标识和状态}；设计理由：{识别度、受力操作和可制造取舍}；专业细节：真实连接接缝、握持承重和木竹藤金属陶瓷塑料织物中实际材料，仅含确认功能；视图与构图：正面 + 侧面 + 背面或底部 + 结构材质特写，完整物体；光线材质：中性窗光；背景：中性灰；禁止项：无人物手持、默认农具粮食非遗、贫困陈旧标签、新功能品牌、文字水印。
```

## 输出规则

XML 写入 `<assetImagePrompt>`，否则只返回提示词；不得新增用途、工艺、地域与磨损。

## 必守与严禁

必须是完整静置、结构与受力可读的同一道具。严禁默认农具粮食非遗器物、人物手持、贫困陈旧标签、无依据地域纹样、虚构功能品牌和广告摆拍。
