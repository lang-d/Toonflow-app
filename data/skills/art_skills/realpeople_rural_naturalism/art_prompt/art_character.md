# 真人乡土自然写实 · 角色基础资产

## 职责与方法

`assetFoundation` 读取身份、年龄段、面容、体态、发型、基础服装、配件和锚点；`visualDesignRationale` 负责识别度、真实可穿戴性和地域材料选择。服装只按确认生活与劳动场合组织层级、面料、鞋履和配件；不默认晒黑、皱纹、破衣、泥污、草帽、围裙或农具。基础状态稳定自然。

## 类型专属设计方法

- 年龄通过骨相、皮下组织、肤质与姿态自然呈现，不用夸张皱纹、晒黑和粗糙皮肤制造乡土标签。
- 体态来自人物事实与日常状态，不能由职业、地域或劳动惯例推导佝偻、消瘦或强壮。
- 服装拆分贴身层、日常层、保暖/防护层和鞋履，说明布料厚薄、织纹、开合、补缀事实与活动余量；不默认破旧。
- 地域材料、头饰和鞋履只有在资产事实中出现才保留，识别度优先由人物自身轮廓、色彩层级和穿着方式建立。
- 头像与正侧背全身保持面容、发型、肩宽、衣长、裤型和鞋履一致，基础状态清洁稳定且无劳动动作。

## 提示词模板（编译顺序）

```text
真人乡土自然写实角色基础设定图，character design sheet；稳定事实：{身份、年龄段、面容、体态、发型、基础服装、确认配件和连续性锚点}；设计理由：{识别度、真实可穿戴与地域材料取舍}；专业细节：真实骨相肤质和自然体态，服装层级、棉麻化纤针织等实际面料、鞋履配件只按事实；视图与构图：头像 + 正侧背全身四视图，同一人物完整一致；光线材质：中性自然窗光；背景：中性灰；禁止项：无晒黑破衣泥污苦相、劳动动作、默认草帽农具方言、地点、文字水印。
```

## 输出规则

XML 写入 `<assetImagePrompt>`，否则只返回提示词；不得残留占位或新增身份、地域与生活状态。

## 必守与严禁

必须是稳定、可复用的真实人物设定图。严禁用晒黑、皱纹、破衣、苦相、方言符号、农具牲畜和劳动姿势塑造乡土感，也不得添加地点剧情。
