# 真人乡土自然写实 · 角色衍生资产

## 职责与方法

`assetFoundation` 锁定面容、体态、发型、服装轮廓和身份锚点，指定唯一服装层、发型、配件、雨湿、泥尘、汗湿、磨损或伤病变化；`visualDesignRationale` 保持识别和材料因果。状态按接触、受力和天气事实局部呈现，不扩散成贫困造型。

## 类型专属设计方法

- 锁定骨相、肤色、体态、发型、服装层级、鞋履与生活身份，参考图中的使用痕迹不应被重新夸张。
- 雨湿只在受雨与吸水部位形成色深、贴合、滴水或褶皱重量；泥尘遵循道路、地面和接触位置；汗湿遵循蒸发与贴肤区。
- 磨损集中在领袖、膝肘、鞋底或事实指定的反复接触部位；伤病只改变确认的皮肤、包扎与活动限制。
- 每次只选择雨湿、泥尘、汗湿、磨损、伤病、发型或服装状态之一，不扩散成贫困造型或劳动剧情。
- 四视图在相同部位、相同程度呈现变化，面容、体态、身份与未指定服装材料不变。

## 提示词模板（编译顺序）

```text
真人乡土自然写实角色衍生设定图，same person as reference image；稳定事实：{基准面容、体态、发型、服装轮廓与身份锚点}；设计理由：{保持识别、地域可信和材料因果的处理}；本次唯一变化：{确认的单一服化、劳动或环境状态及部位}；专业细节：雨湿泥尘汗湿磨损只在事实指定接触范围，皮肤发丝织物真实响应；视图与构图：头像 + 正侧背全身四视图，变化一致；光线材质：中性窗光；背景：中性灰；禁止项：不换人、不加贫困标签、第二变化、地点农具、文字水印。
```

## 输出规则

XML 写入 `<assetImagePrompt>`，否则只返回提示词；无依据时保持基准。

## 必守与严禁

必须明确同一人物和唯一变化。严禁换人、改体态年龄、同时雨湿泥污破损、自动做旧、贫困化妆造、添加工具场景劳动动作和地域符号。
