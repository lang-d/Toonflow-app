# 3D乡村漫剧 · 道具衍生设定图

## 职责与方法

生成同一道具的一项确认状态变化，不换物，不增加功能，不生成剧情现场。

- **assetFoundation**：锁定名称、用途、尺度、轮廓、主体结构、连接、开合逻辑、材料、颜色、标识和归属。
- **参考图**：是形体、尺度、材料、接缝和活动件的连续性基准。
- **visualDesignRationale**：只解释本次变化如何可读并保持同一物件，不做功能升级和装饰重设计。
- **单一变化**：一次只处理开合、装载/使用、湿润/干燥、泥尘、磨损、修补、裂纹、缺损或损坏中的一项确认变化。

外层资产流程将最终提示词写入 `<assetImagePrompt>`；直接调用只输出最终提示词正文。

## 类型专属设计方法

### 一、不可变锚点

| 锚点 | 必须保持 |
|---|---|
| 用途 | 不因状态改变产生新功能 |
| 尺度与容量 | 外形尺度、容积事实和角色交互尺度不变 |
| 核心轮廓 | 主体体块、开口、把手、支撑和工作端不变 |
| 连接与开合 | 活动方式、连接件数量和运动方向不变 |
| 材料层级 | 主材、辅材和连接件不互换 |
| 颜色与标识 | 未受状态影响的颜色、图形和已确认文字不变 |
| 归属与年代 | 不因磨损或修补改变来源、身份和年代 |

### 二、单一变化矩阵

| 变化 | 需要呈现 | 不得扩展 |
|---|---|---|
| 开启/闭合 | 活动件方向、连接点、内部可见范围 | 不增加内部零件和内容物 |
| 装载/使用状态 | 已确认内容物、受力、重心或接触范围 | 不自动增加人物、工具和环境 |
| 湿润/干燥 | 颜色、反射、重量、挺度或纤维变化 | 不自动产生泥尘、锈蚀和霉变 |
| 泥尘/砂粒 | 接触区、飞溅方向、附着和遮盖程度 | 不扩散到无接触面 |
| 磨损 | 边缘、握持区、接地面或活动件的摩擦结果 | 不等同破损、缺件和报废 |
| 修补 | 已确认材料、覆盖区、固定方式和原损伤关系 | 不把修补做成新设计或功能 |
| 裂纹 | 起点、受力方向、材料纹理和终止位置 | 不跨越不相连材料 |
| 缺损/损坏 | 缺失部位、断面、变形和对功能的确认影响 | 不擅自扩大严重度和后果 |

宽泛的“旧了”“用过了”“灾后”“坏了”必须由输入明确成一个可见状态；否则保持基准。

### 三、材料传播规律

| 材料 | 状态变化规律 |
|---|---|
| 纸张/纸箱 | 湿润降低挺度并改变边缘；压痕沿折线和受力面；撕裂从边口或切口传播 |
| 竹木 | 水分沿纤维改变色深；磨损集中接触面；裂纹沿纹理和节点传播 |
| 塑料 | 划痕沿摩擦方向；变形与温度/受力事实对应；泥尘附着在凹槽和接地面 |
| 金属 | 划痕暴露方向明确；锈蚀只在已确认暴露、水分和时间条件下出现；凹陷服从冲击 |
| 玻璃/陶瓷 | 裂纹从受力点扩散，断面与材料厚度一致；不自动粉碎 |
| 织物/帆布 | 湿润沿重力和纤维扩散；磨损集中折叠、拉扯与边缘；修补有缝合或覆盖结构 |
| 绳索 | 磨损沿受力与摩擦区，断股方向对应编织结构；不自动新增绳结 |
| 橡胶 | 压缩、磨耗、裂口和回弹服从接触与受力，不做金属式划痕 |

状态只传播到有物理连接、接触、重力、吸水或受力依据的范围。

### 四、对照视图

选择最能证明“同一物件＋一项变化”的视图：

- 保留一个与父级参考一致的基准角度；
- 增加能看到变化位置和范围的主视图；
- 对连接、断面、开合、修补或材料边缘使用局部特写；
- 必要时补背面或底部，证明变化没有跨越未受影响结构；
- 所有视图保持同一尺度、颜色、标识和稳定部件；
- 道具始终独立展示，不出现人物、手、使用现场和广告环境。

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

- 资产流程写入 `<assetImagePrompt>`，直接调用只返回最终提示词正文；
- 必须指出唯一变化、作用材料、发生位置和传播边界；
- 输入未确认变化时保持稳定基准；
- 不输出分析、多方案、Markdown、模板说明和未替换占位符。

## 必守与严禁

### 必守

- 同一用途、尺度、轮廓、结构、材料和标识；
- 一次只处理一个状态维度；
- 材料变化有接触、吸水、重力、摩擦或受力依据；
- 变化视图与基准角度共同证明同一物件；
- 未受影响区域保持原状。

### 严禁

- 不把使用自动等于磨损，把湿润自动等于锈蚀或霉变；
- 不把破损自动扩大为报废，不推断剧情后果；
- 不增加人物、手、地点、作物、工具、品牌、内容物和新功能；
- 不改变容量、开合方向、连接方式和归属；
- 不附加与同一道具连续和本次唯一变化无关的技术控制语句。
