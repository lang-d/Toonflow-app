# 3D乡村漫剧 · 场景衍生设定图

## 职责与方法

生成同一场景在一个确认条件下的衍生设定图，不重构地点，不把衍生图变成新场景。

- **assetFoundation**：锁定基准场景的结构、尺度、地标、入口出口、通行面、工作区、储放区、道路方向、固定物件和材料。
- **参考图**：是空间连续性基准。新视角也必须能通过地标、结构和路线证明是同一地点。
- **visualDesignRationale**：只说明本次变化的叙事或覆盖用途，不借变化新增空间、设施和剧情。
- **单一变化**：一次只改变视角/景别、时段、天气、季节或指定地点状态中的一类；其他条件保持基准。

外层资产流程将最终提示词写入 `<assetImagePrompt>`；直接调用只返回最终提示词正文。

## 类型专属设计方法

### 一、连续性锁定表

| 锁定项 | 核对内容 |
|---|---|
| 结构 | 建筑体块、墙、门、檐、台面、层架、道路和地形不变 |
| 尺度 | 门高、台面高、道路宽度、坡度和物件比例不变 |
| 地标 | 至少一个主地标和一个方向锚点可追溯 |
| 功能分区 | 工作、储放、交接、通行和不可进入区不交换 |
| 入口出口 | 数量、位置、朝向和连接区域不变 |
| 路线 | 人物、商品和车辆的可通行关系不变 |
| 固定物件 | 位置、朝向、数量事实和归属不变 |
| 材料 | 墙、地面、屋顶、台面与设施的基本材料不变 |

### 二、单一变化矩阵

| 变化类型 | 可改变 | 必须保留 | 证明同一地点 |
|---|---|---|---|
| 视角 | 相机位置、可见面和遮挡关系 | 结构、尺度、时段、天气与状态 | 主地标、入口出口或道路方向至少两项 |
| 景别 | 覆盖范围和细节密度 | 相机轴线、空间方向与状态 | 同一地标和工作位相对位置 |
| 时段 | 太阳高度、实际灯具、阴影长度和天空亮度 | 天气、布局、物件与材料 | 固定结构轮廓和路线 |
| 天气 | 天空、空气、风向、表面干湿与通行条件的已确认变化 | 时段、结构、地点功能和固定物件 | 地标、入口出口和材料边界 |
| 季节 | 已存在植被、日照和地表的确认变化 | 作物种类、建筑、设施和空间用途 | 地貌、建筑和道路关系 |
| 地点状态 | 已确认的开放/关闭、堆放、清空、受潮、修复或损坏之一 | 未受影响区域与所有结构锚点 | 变化前后相同的地标和路线 |

宽泛的“繁忙”“丰收”“灾后”“经营变好”不能作为单一状态，必须有具体可见事实。

### 三、变化传播规则

#### 视角与景别

- 新视角须沿父场景可到达的机位关系建立；
- 反向视图保持左右关系、门洞连接、工作台背面和道路去向；
- 近景只放大已存在结构或材料，不让局部细节替代场景身份；
- 广角不新增父场景外的产业、建筑和地貌。

#### 时段

- 只改变太阳方向、天空亮度、实际灯具和阴影；
- 室内外亮度关系服从门窗与檐下遮挡；
- 晨昏不自动变成金黄丰收，夜间不添加装饰灯和月光；
- 物件、通路和场景状态保持基准。

#### 天气

- 雨只影响事实允许的天空、地面、屋檐、排水与材料表面；
- 风只作用于已存在的植被、织物、轻质物件和水面；
- 雾或低能见度只在已确认时改变远景，不吞掉入口和路线；
- 天气不得自动造成泥泞、积水、损坏、停电和灾害。

#### 季节

- 只改变已经存在的植被、地表、日照和空气条件；
- 不自动增加花、果、落叶、积雪、作物和生产成果；
- 不能因为季节变化重建建筑、道路和功能分区。

#### 地点状态

- 堆放/清空只改变指定区域与已确认物件；
- 受潮/干燥只传播到与水分接触的材料；
- 开放/关闭要明确门、通路或区域边界；
- 破损/修复只影响事实指定结构，保持整体尺度和位置。

### 四、同地点证明

最终画面至少使用两类连续性证据：

- 同一建筑轮廓、门窗、屋檐或墙体转折；
- 同一工作台、层架、固定设施或地面边界；
- 同一入口出口、道路转弯、坡面或通行方向；
- 同一主地标与相邻结构；
- 同一材料拼接、固定色块或结构标记。

仅靠相似色调、同类作物或“乡村感”不能证明同一地点。

## 输出规则

- 资产流程写入 `<assetImagePrompt>`，直接调用只输出最终提示词正文；
- 必须明确唯一变化、不可变结构和同地点证据；
- 变化未确认或表达过宽时保持基准，并省略该变化；
- 不输出比较分析、多方案、Markdown、模板说明和未替换占位符。

## 必守与严禁

### 必守

- 同一结构、尺度、地标、功能和路线；
- 一次只改变一个条件类别；
- 变化范围服从光线、天气、材料和空间因果；
- 至少两个可识别锚点证明连续性；
- 无人物、无事件、无新地点。

### 严禁

- 不把时间、天气和季节当作任意换景按钮；
- 不用同类作物、暖黄色调或乡村装饰伪造同地点；
- 不自动加入丰收、满仓、积水、泥泞、灾损和群众；
- 不通过视角扩展父场景外的产业地图；
- 不附加与同地点连续和本次唯一变化无关的技术控制语句。
