# 3D乡村漫剧 · 道具基础设定图

## 职责与方法

本手册生成可复用的三维卡通道具基础设定图，不生成人物手持、广告图、生产现场或剧情结果。

- **assetFoundation**：读取名称、用途、尺寸或尺度关系、核心轮廓、结构、连接、开合、材料、颜色、标识、默认状态和归属事实。
- **visualDesignRationale**：只把轮廓识别、功能可读、抓握/接触和动画需求落实为结构，不新增用途、功能、品牌和剧情。
- **基础资产边界**：表现完整、稳定、可复用状态。开启、受潮、泥尘、磨损、修补、缺损和损坏只在它们是稳定事实时进入，否则留给衍生资产。
- **纯道具图**：画面中不出现人物、手、身体、佩戴、使用动作或剧情环境。

外层资产流程将编译后的纯图片提示词写入 `<assetImagePrompt>`；直接调用只输出最终提示词正文。

## 类型专属设计方法

### 一、功能结构诊断

先从事实建立结构，不按“农业道具”套类别。

| 诊断项 | 需要明确 | 设计作用 |
|---|---|---|
| 用途 | 装、盛、切、称、连接、保护、运输、记录或其他确认功能 | 决定主要形体与操作面 |
| 尺度 | 实际尺寸、与角色/容器的相对尺度或未知 | 决定抓握、搬运和画面占比 |
| 核心轮廓 | 主体体块、开口、把手、支撑与突出部 | 建立远看识别 |
| 接触区 | 手握、放置、承重、接地、装载或连接位置 | 支持后续动作与受力 |
| 开合/活动 | 铰链、盖、扣、轮、抽拉、折叠或无活动结构 | 避免模型无法操作 |
| 连接 | 榫接、缝合、绳结、紧固、焊接、粘接等确认方式 | 决定材料交界与破损逻辑 |
| 材料层级 | 主材、辅材、连接件、透明/柔软部件 | 区分厚度、粗糙度和高光 |
| 标识 | 已确认的颜色块、图形、编号或文字 | 只呈现真实内容；未知时保持无字 |

没有尺寸时不发明数值。可使用“单手可握、双手搬运、与既有容器匹配”等事实允许的相对尺度；仍无法判断则避免伪精确。

### 二、道具类型与建模重点

| 结构类型 | 建模重点 | 需要核对 |
|---|---|---|
| 容器类 | 容积体块、壁厚、开口、底部、把手与堆叠关系 | 是否可提、可倒、可封、可叠 |
| 包装类 | 折线、封口、插舌、缓冲层、标签区域 | 展开/闭合逻辑和承重方向 |
| 手工具类 | 握持区、工作端、重心、护手和连接 | 手部尺度、用力方向和安全边界 |
| 运输/承载类 | 支撑、轮轴、把手、载荷区和接地 | 推拉方向、转向与负重 |
| 记录/信息类 | 开合、页面/屏幕、按键、标识区域 | 内容归属、可读方向与操作面 |
| 穿戴/防护类 | 与身体接触面、固定方式、调节和活动余量 | 只在道具独立状态展示 |
| 生活器物 | 容纳、倒取、开合、稳定和清洁结构 | 不因乡村题材增加装饰 |

类型只在输入支持时选择。不能自动加入果筐、电子秤、农具、包装箱、车辆、直播设备或品牌。

### 三、材料与结构规律

| 材料 | 基础表现 | 结构细节 |
|---|---|---|
| 纸张/纸箱 | 哑光、纤维大形、边缘厚度 | 折边、压线、插舌、胶带或封口 |
| 竹材 | 节点、纵向纤维、轻微弯曲 | 编结、绑扎、榫接或切口仅按事实 |
| 木材 | 纤维方向、截面和重量 | 榫接、螺钉、钉合或胶合 |
| 塑料 | 壁厚、注塑轮廓、有限高光 | 加强筋、把手、卡扣和开口 |
| 金属 | 厚度、重量、边缘和冷暖高光 | 折弯、冲压、焊接、铆接或紧固 |
| 玻璃 | 壁厚、透明/半透明、边缘折射 | 开口、底部、盖或连接部 |
| 陶瓷 | 体积、釉面与未上釉边缘 | 口沿、底足和厚度 |
| 织物/帆布 | 经纬大形、垂坠和张力 | 缝线、包边、带子和固定点 |
| 绳索 | 股线、直径、端头和弯曲 | 绳结只有事实确认时出现 |
| 橡胶 | 哑光、弹性、压缩和回弹 | 防滑纹、密封和接触面 |

卡通化应简化微小噪声，但保留结构厚度、接缝、受力和材料差异。不能把木、竹、纸、塑料和金属都渲染成同一种光滑表面。

### 四、受力、重心与交互

- 把手、握持区和接触面应能容纳既有角色手部；
- 承载类道具要有稳定底面、支撑点和合理重心；
- 开合件说明旋转、滑动、折叠或拆卸方向；
- 软质道具说明悬挂点、张力方向与空载形态；
- 轮子、轴、铰链、扣件和接口必须与主体连接；
- 装载口、倒出口、工作端和危险边界只有事实存在时表现；
- 道具可交互不等于必须展示使用动作，基础图仍为独立静物。

### 五、多视图规范

视图根据结构选择，不机械固定四宫格：

1. 正面或主要功能面：确认核心轮廓、开口和标识；
2. 侧面：确认厚度、重心、把手、活动件和受力方向；
3. 背面或底部：确认连接、支撑、接口和不可见结构；
4. 关键结构特写：确认接缝、开合、材料交界或工作端。

复杂开合结构可补充闭合状态的结构示意，但基础图不自动制作衍生状态。所有视图为同一物件、同一尺度、同一材料和同一稳定状态，完整不裁边。

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

- 资产流程将最终提示词写入 `<assetImagePrompt>`；
- 直接调用只输出最终提示词正文；
- 无法确定的尺寸、材料和结构不得伪造精确数值；
- 最终不得保留占位符、模板说明、多个方案、Markdown 或分析。

## 必守与严禁

### 必守

- 用途、尺度、结构、连接和材料来自确认事实；
- 轮廓、重心、接触和活动件支持后续三维交互；
- 多视图共同证明同一物件的完整结构；
- 基础资产保持稳定、完整、未使用状态；
- 标识内容不明时保持无字或仅保留已确认图形。

### 严禁

- 不因种田经营题材自动增加任何生产、包装、运输和直播道具；
- 不凭审美增加品牌、文字、功能、装饰和年代信息；
- 不出现人物局部、手持、穿戴、广告构图和剧情环境；
- 不自动添加泥尘、受潮、锈蚀、划痕、破损和修补；
- 不附加与道具结构、材料和视图设计无关的技术控制语句。
