# 3D乡村漫剧 · 场景基础设定图

## 职责与方法

本手册生成可反复使用的三维卡通场景基础设定图，不生成正在发生的生产事件、人物剧情或经营结果。

- **assetFoundation**：读取场景名称、区域类型、固定结构、出入口、功能分区、道路方向、地标、材料、关键物件、通行面和安全边界。
- **visualDesignRationale**：只解释怎样提高空间识别、路线可读、工作调度和镜头覆盖，不新增地点、设施、作物或事件。
- **基础资产边界**：表达地点默认稳定状态。临时时段、天气、潮湿、泥泞、堆满、清空、损坏、收获和灾后状态不自动固化。
- **无人场景**：不出现人物、人影、动物、正在操作的物件或剧情痕迹，除非某对象本身是场景资产的稳定结构事实。

资产基础流程把最终提示词写入 `<assetImagePrompt>`；直接调用只输出最终提示词正文。

## 类型专属设计方法

### 一、场景分类与事实选择

以下分类只用于选择空间方法，不意味着自动存在。

| 已确认场景类型 | 需要优先建立 | 不得自动补入 |
|---|---|---|
| 生产区/种养区域 | 边界、作业面、行列/分区、入口、通行路径和地貌 | 特定作物、丰收成果、农机、工人 |
| 院坝/家庭工作区 | 建筑开口、半室外边界、工作位、储放位和通路 | 晾晒、炊烟、家禽、节庆布置 |
| 检查/包装位 | 台面、待处理区、已处理区、容器流向和人员站位余量 | 电子秤、标签、纸箱、流水线 |
| 储放空间 | 入口、堆放区、层架/地面容量、通风和取放路线 | 商品数量、满仓、冷库设备 |
| 道路/短驳路线 | 来向、去向、转弯、坡度、路面和停靠关系 | 车辆、路牌、游客、航拍景观 |
| 揽收/交接点 | 双方可达面、车辆/人物位置、装卸区与出口 | 快递车、站点标识、订单人群 |
| 生活或公共空间 | 已确认功能、入口、活动面和相邻关系 | 乡村符号拼贴、广场舞、集市 |

### 二、功能拓扑

场景设计先画“如何使用”，再画“看起来如何”。

1. **区域边界**：墙、门、沟、坡、植被、地面变化或设施怎样划分空间；
2. **入口出口**：人物、商品、容器和车辆分别从哪里进入、离开；
3. **主要工作位**：操作面、身体活动余量、手物接触位置和视线方向；
4. **待处理/已处理区**：只有事实存在时区分，且不能混放；
5. **储放位**：高度、深度、可达性与取放方向；
6. **道路与返回路线**：起点、转折、停靠和回到工作位的关系；
7. **地标**：使用一至两个稳定结构帮助识别方向，不堆装饰；
8. **安全边界**：高差、水域、车行、狭窄口或不可进入区只有事实确认时标出。

前景、中景和后景必须承担空间功能：

- 前景提供进入、框景或可接近边界；
- 中景承载主要工作区、交接点或空间关系；
- 后景证明出口、道路延伸、相邻区域或稳定地标。

层次不等于装饰堆叠。不能为了纵深增加不存在的作物、农具、动物和建筑。

### 三、尺度与动画可行性

- 门、台面、道路、坡度、层架和容器位置须与既有角色及物件尺度协调；
- 工作位周围预留站立、转身、弯腰、搬运和递交空间；
- 车辆路线与人物通路冲突时，仅表现事实已确认的关系，不擅自改造场地；
- 台面边缘、门槛、台阶、坡面和水边须有可见碰撞边界；
- 可移动物件与固定结构分层，避免后续动画无法判断哪些部分可操作；
- 背面或反向区域若承担反复行动，应在辅助视图中补足，不以不可见结构猜测。

### 四、季节、时段与光线

季节只影响已经存在的植被、地表、空气、日照和生产对象；不自动改变作物、建筑、布置或经营状态。

| 条件 | 光线组织 | 材质响应 |
|---|---|---|
| 开阔日光 | 明确太阳方向和建筑投影，工作面不过曝 | 地面与建筑保留粗糙度，商品有限高光 |
| 树冠/棚架下 | 用少量大形筛光区分遮蔽与通行 | 不用密集光斑覆盖路线 |
| 阴天 | 漫射光降低反差，以色相和粗糙度分区 | 湿润只有事实支持时出现 |
| 檐下/半室外 | 平衡亮院坝、暗檐下和门洞过渡 | 入口、台面和人物预留区可读 |
| 室内储放/包装 | 只使用确认门窗与灯具的动机光 | 待处理区、容器和通路清楚 |
| 晨昏 | 低角度光服务方向和时段，不固定金黄 | 保住材料本色与入口出口 |

不要求固定色温、暖色、黄昏、浅景深或镜头光学效果。场景设定图首先保证结构与材质可读。

### 五、3D乡村材质

| 材质 | 建模与卡通化重点 | 禁止退化 |
|---|---|---|
| 土、石、道路 | 地形大面、颗粒尺度、裂纹方向、压实/松散区别 | 用同一棕色噪声覆盖所有地面 |
| 砖、瓦、混凝土 | 块面、接缝、边缘厚度与重量 | 自动破旧、长苔或开裂 |
| 竹木 | 节点、纤维方向、连接和受力弯曲 | 只贴木纹而没有结构 |
| 纸箱/纸材 | 壁厚、折边、压线、封口与堆叠支撑 | 无厚度纸片或默认受潮 |
| 塑料 | 注塑大形、壁厚、半哑光和有限透光 | 所有塑料镜面发亮 |
| 金属 | 型材、紧固、焊接或折边和有限高光 | 无重量的亮银玩具 |
| 织物/篷布 | 悬挂点、张力、折线和遮挡范围 | 无支撑悬浮或无限平滑 |
| 植被 | 簇群、层级、风向与季节事实 | 逐叶噪声、默认花海 |
| 水与湿面 | 水体边界、反射方向和接触面 | 无来源积水或整场镜面 |

材料的使用痕迹、泥尘、压痕、受潮和破损必须来自 assetFoundation；默认状态不强制“岁月感”。

### 六、主视图与辅助视图

主视图选择最能同时证明以下内容的角度：

- 场景主体和固定结构；
- 入口出口与主要路线；
- 工作区、储放区或交接点的关系；
- 一至两个识别地标；
- 前中后景的功能层次。

必要时增加辅助视图：

- 入口或出口反向关系；
- 工作位背面与台面布局；
- 道路转折和停靠点；
- 室内外连接；
- 父视图遮挡的重要固定结构。

辅助视图不是多种设计方案，必须保持同一布局、尺度、材料和方向。若外层只允许单图，选择信息最完整的主视图，不拼接无关视角。

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

- 资产基础流程将最终提示词写入 `<assetImagePrompt>`；
- 直接调用只输出最终提示词正文；
- 最终提示词必须包含固定结构、路线、至少一个空间识别锚点和材料逻辑；
- 不保留占位符，不输出多个备选方案、分析、Markdown 或模板说明。

## 必守与严禁

### 必守

- 固定布局、功能拓扑和路线先于氛围；
- 所有空间、设施、作物、动物和关键物件均需事实来源；
- 主视图能支持后续人物走位、物件移动和机位覆盖；
- 材质通过结构、厚度、接缝、粗糙度和受力区分；
- 基础场景保持默认稳定状态。

### 严禁

- 不把场景拼成乡村符号合集、旅游景观或童话农场；
- 不默认金黄丰收、炊烟、晒场、农机、家禽和满仓；
- 不强制自然磨损、泥泞、受潮、黄昏和浅景深；
- 不出现人物、劳动事件、剧情证据和经营结果；
- 不附加与空间事实、光线和材质设计无关的技术控制语句。
