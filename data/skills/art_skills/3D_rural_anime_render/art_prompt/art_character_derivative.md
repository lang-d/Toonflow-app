# 3D乡村漫剧 · 角色衍生设定图

## 职责与方法

生成同一基准角色的一项确认变化，不重做人设，不生成剧情镜头。

- **assetFoundation**：锁定身份、脸部拓扑、年龄感、体态、身体比例、稳定发型、服装体系、鞋履、配件位置和颜色锚点。
- **参考图**：是面容、比例、材质和背面结构的连续性基准；新文字不得把角色改成“同风格的另一个人”。
- **visualDesignRationale**：只说明本次变化怎样清楚可读并保持同一人，不得升级身份、职业、能力或审美等级。
- **单一变化**：调用方只指定一个变化维度；如果输入包含多个变化，按明确的主变化处理，其余只保留为不可变事实或标记待确认。

外层资产流程要求 XML 时，将最终纯图片提示词写入 `<assetImagePrompt>`；直接调用只输出最终提示词正文。

## 类型专属设计方法

### 一、不可变锚点

每次先列出并锁定：

| 锚点 | 必须保持 |
|---|---|
| 身份与年龄感 | 不因服装、污渍或状态改变 |
| 脸部拓扑 | 额颞、眉眼、鼻口、下颌、耳形及肤色基准 |
| 体态与比例 | 骨架、四肢比例、重心和站姿基准 |
| 发型基准 | 除非本次唯一变化就是发型，否则分缝、长度、卷直和大形不变 |
| 服装体系 | 除非本次唯一变化就是服装，否则层级、版型、颜色与开合不变 |
| 鞋履与配件 | 位置、尺度、固定方式和材料不变 |
| 3D结构 | 关节、衣物厚度、背面结构和绑定空间不变 |

### 二、单一变化分类矩阵

| 变化类型 | 可改变 | 必须锁定 | 传播边界 |
|---|---|---|---|
| 发型/妆造 | 输入指定的发型组织、配件或妆容 | 脸部拓扑、年龄感、体态、未指定服装 | 只影响头部和明确关联配件 |
| 服装 | 指定的穿着层、开合或配件 | 面容、体态、发型基准、未替换层 | 服装变化不自动带来职业和地点 |
| 雨湿/水湿 | 发丝贴合、布料色深、垂坠和有限反射 | 人物身份、体态和干燥区域 | 沿重力、接触与吸水材料传播 |
| 汗湿 | 已确认部位的局部色深和贴合 | 未受影响服装、发型和肤色 | 不能泛化成疲劳、泥污或伤病 |
| 泥尘/污渍 | 接触区、飞溅方向和材料附着 | 轮廓、服装结构和非接触区 | 有地面、动作或接触来源 |
| 磨损/破损 | 受力边缘、接缝、袖口、膝肘等确认位置 | 未指定部位与服装体系 | 沿摩擦、拉扯或材料纹理发生 |
| 伤病 | 已确认位置、外观和活动限制 | 身份、体态基准和未受影响部位 | 不自行增加血迹、包扎或严重度 |
| 情绪/疲劳外观 | 已确认的眼睑、嘴角、姿态微差 | 脸型、身体比例和服装状态 | 不把短时表演固化成新身份 |

“工作状态”“赛后状态”“狼狈状态”等宽泛词不能直接编译，必须拆成一个可见变化；无法确定时保持基准。

### 三、材料传播规律

- **头发**：湿度从外层和发尾产生聚束、贴合和重量变化；不自动变成长发、散发或脏乱；
- **棉麻织物**：吸水后色深、垂坠和褶皱尺度改变，干燥区保持原材料；
- **针织/弹性材料**：变化沿拉伸与接触区出现，不破坏原纹理方向；
- **防水/合成材料**：水分形成有限水膜或珠状高光，不等同整件湿透；
- **鞋履**：泥尘或水分集中在鞋底、鞋面接触区，不蔓延到全身；
- **皮肤**：伤病、晒红或污渍只有事实明确时出现，范围、边缘和颜色克制；
- **金属/塑料配件**：保持硬质轮廓，状态变化不与织物同步变形。

### 四、四视图与对照

角色衍生图仍以四视图确认同一人：

- 正面头像近景显示脸部是否保持一致及变化是否影响面部；
- 正面全身显示变化在整体造型中的比例；
- 侧面全身显示材料厚度、贴合、发型侧形和身体轮廓；
- 背面全身显示发型、衣物、配件和状态传播是否闭合。

如唯一变化只在局部，允许用局部变化特写替代重复信息，但仍须保留正面、侧面和背面中的连续性证据。站姿保持中性，不把输入中的剧情动作固化到设定图。

```text
3D乡村漫剧同一角色衍生设定图，same person as reference image；稳定事实：{基准角色、参考图与 assetFoundation 中不可改变的身份、脸部拓扑、年龄感、体态比例、发型基准、服装体系、鞋履、配件、颜色和3D结构锚点}；设计理由：{visualDesignRationale 中对本次唯一变化的可读性、传播范围和同一人识别策略}；专业细节：仅呈现{已确认的一项发型、妆造、服装、雨湿、汗湿、泥尘、磨损、伤病或其他可见变化}，按头发、皮肤、织物、鞋履或配件的材料规律限制影响范围，未指定部位完全保持基准；视图与构图：正面头像近景、正面全身、纯侧面全身、背面全身或必要的变化细节对照，四视图同一身份、同一比例、同一次衍生状态，中性站姿、完整无遮挡；光线材质：中性稳定展示光，卡通明暗和有限高光保持基准材质，变化边缘、重力方向、接触位置与受力依据清楚；背景：沿用基准角色的中性低干扰设定背景；禁止项：不得换人、改脸型、改年龄、改体态、升级身份、同时更换多个层级、增加劳动动作、工具、动物、地点、他人、品牌、文字或无依据状态。
```

## 输出规则

- 资产流程将最终提示词写入 `<assetImagePrompt>`；
- 直接调用只返回最终提示词正文；
- 必须明确写出“唯一变化”和“未改变的锚点”；
- 没有确认变化时维持基准，不用乡村题材补写；
- 不输出模板说明、分析、Markdown、未替换占位符或额外方案。

## 必守与严禁

### 必守

- 参考图与父级角色优先；
- 一次只改变一个维度；
- 变化须有位置、范围、方向和材料因果；
- 正面、侧面和背面均能证明是同一角色；
- 未指定内容全部锁定。

### 严禁

- 不把湿度、泥尘、磨损、伤病、围裙、草帽和工作服作为默认衍生；
- 不因“乡村”“劳动”“经营”升级年龄、职业、体态或贫困外观；
- 不把一项雨湿扩展为泥污、疲劳、破损和伤病；
- 不新增剧情动作、工作地点、手持物和人物关系；
- 不附加与本次唯一变化无关的技术控制语句。
