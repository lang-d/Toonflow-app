# 3D乡村漫剧 · 角色基础设定图

## 职责与方法

本手册负责生成可复用的三维卡通角色基础设定图，不负责剧情镜头、劳动动作、人物关系或临时状态。

- **assetFoundation**：只读取已经确认的身份、年龄感、性别表达、面容、体态、发型、基础服装、鞋履、配件和稳定颜色锚点；不得反向改写事实。
- **visualDesignRationale**：只把识别度策略、审美修正和动画可行性落实为可画特征；不能新增身份、职业、地域、能力和剧情。
- **基础资产边界**：表现角色可跨场次复用的默认稳定状态。汗湿、雨湿、泥尘、晒伤、疲劳、伤病、破损、劳动姿势和手持物均不自动进入基础图。
- **占位项**：模板花括号是编译顺序，最终必须用事实与设计结论填实，不得原样输出。

### 输出模式

1. 外层资产基础设定流程要求 XML 时，遵守外层契约，将纯图片提示词写入 `<assetImagePrompt>`。
2. 直接任务调用时只输出最终提示词正文，不输出 XML、Markdown、分析、表格、模板说明或代码围栏。

## 类型专属设计方法

### 一、角色识别层级

按从稳定到可设计的顺序组织，不用服饰标签替代人物本身。

| 层级 | 读取或设计内容 | 判断边界 |
|---|---|---|
| 身份事实 | 年龄感、性别表达、职业/家庭身份、稳定身体事实 | 只来自输入，不由乡村题材推断 |
| 面部锚点 | 脸部骨相、额颞轮廓、眉眼间距、鼻口关系、下颌与耳形 | 未给出时允许差异化设计，但不套固定男女脸 |
| 体态锚点 | 身高感、骨架宽窄、躯干与四肢比例、重心和站姿倾向 | 不按职业、项目或地域自动推导肌肉和胖瘦 |
| 发型锚点 | 发际线、分缝、长度、卷直、发量、前后大形 | 发型须能在正侧背视图闭合 |
| 服装锚点 | 贴身层、主服装、外层、腰线、袖口、裤/裙脚、鞋履 | 只使用已确认的常态服装，不默认围裙、草帽和劳作服 |
| 配件锚点 | 位置、固定方式、材质、尺度和是否长期佩戴 | 无事实时不增加眼镜、首饰、证件、工具和品牌 |
| 色彩锚点 | 皮肤、头发、主服装、辅助层和小面积识别色 | 服从资产事实，不套暖黄、田园绿或治愈色盘 |

识别度优先来自面部大关系、体态轮廓、发型大形和服装层级。复杂花纹、地域符号、农具、动物和道具不能作为主要识别手段。

### 二、面部拓扑与年龄感

- 先建立额头—眉弓—眼眶—颧骨—鼻基底—口周—下颌的连续体块，再做卡通化简化；
- 年龄感来自骨相、软组织分布、眼睑、口周、发际线和站姿的共同关系，不只靠皱纹；
- 眉眼、鼻口和耳朵在正面、侧面和背面转折处保持同一高度关系；
- 眼睛可以卡通化放大，但眼眶位置、视线方向和左右对称应支持表情绑定；
- 口角、脸颊和下颌保留张口、微笑、说话和咀嚼所需的变形空间；
- 皮肤采用简化色块与柔和粗糙度，不追求毛孔堆叠，也不把所有年龄做成光滑娃娃脸；
- 不以晒黑、红脸、雀斑、风霜纹或“朴实脸”制造乡村身份。

### 三、体态、关节与绑定

| 部位 | 设计要求 | 动画检查 |
|---|---|---|
| 颈肩 | 头颈连接、肩线和衣领层级清楚 | 转头、抬臂时不穿领口 |
| 躯干 | 胸廓、腰胯和重心关系明确 | 弯腰、搬运、转身时体积不塌陷 |
| 手臂与袖子 | 肘部位置、袖口厚度和活动余量可读 | 抓握和递交时袖口不遮手 |
| 手部 | 掌宽、指长、拇指方向和抓握空间合理 | 能接触输入中可能复用的物件尺度 |
| 髋膝踝 | 关节位置与鞋底支撑一致 | 蹲起、行走和负重时重心成立 |
| 服装软部件 | 衣摆、围巾、长发等仅按事实存在 | 有分段与惯性空间，不与身体粘死 |

不要写固定身高、固定头身比或固定性别体态。只有输入提供尺度时才明确数值；否则用“与既有角色及场景尺度协调”。

### 四、发型结构

- 将头发组织为头皮贴合层、主要发块、前额/侧鬓、后部轮廓和必要的束缚点；
- 正面负责发际线、分缝与脸部框景；侧面负责头颅体积、耳部遮挡和发尾位置；背面负责分组、束发结构和衣领关系；
- 长发、卷发、短碎发或扎发只在事实成立时使用，不按性别默认；
- 卡通发束保持大形清楚，避免密集独立发丝导致闪烁和穿模；
- 发饰、皮筋、夹子或帽子须有固定方式和背面结构，事实未提供时不添加。

### 五、服装层级与材料

先确认穿着结构，再处理三维材质。

| 层级 | 需要说明 | 3D卡通表现 |
|---|---|---|
| 贴身层 | 领口、袖长、下摆及外露范围 | 体积克制，不形成不必要紧身或暴露 |
| 主服装 | 版型、开合、口袋、腰线、裤/裙结构 | 大折线清楚，关节处留活动量 |
| 外层 | 夹克、外套、防护层等已确认内容 | 厚度、内外层和扣合位置可读 |
| 鞋履 | 鞋口、鞋底、闭合方式和使用场景 | 鞋底接地，前后侧轮廓一致 |
| 配件 | 固定点、尺度、材质与长期性 | 不遮挡脸部、手部和关节 |

材料表现：

- 棉、麻与普通织物：哑光、柔和折线、边缘厚度与缝线大形；
- 针织：以块面和弹性褶皱表达，不堆密集纤维；
- 防水或合成材料：有限宽高光和较硬折线，仅在事实存在时使用；
- 橡胶鞋底：较低反射、清楚厚度与接地面；
- 金属扣件：小面积高光，不把服装整体塑料化。

基础服装保持正常、清洁和可复用，除非资产事实明确指定稳定磨损。

### 六、四视图规范

同一画面展示：

1. 正面头像近景：完整头顶至肩颈，确认脸部拓扑、发际线与肤色；
2. 正面全身：确认整体轮廓、重心、服装层级和鞋履；
3. 纯侧面全身：确认面部侧形、头颅体积、胸背关系和衣物厚度；
4. 背面全身：确认发型背面、衣领、背部结构、口袋/开合与鞋后跟。

所有视图须为同一人物、同一基础造型、同一身体比例和同一颜色分区。保持中性站姿、双手可见、无遮挡、完整头到脚；不要求固定画幅和固定背景色，只使用中性低干扰设定背景与稳定展示光。

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

- 基础资产流程只把编译后的图片提示词写入 `<assetImagePrompt>`；
- 直接调用只输出最终提示词正文；
- 模板中的每一项都应由输入事实或设计判断填实；无事实的可选项应省略或写成中性设计，不保留占位符；
- 不输出分析、替代方案、Markdown、XML 外壳、表格或说明。

## 必守与严禁

### 必守

- 角色识别来自脸部、体态、发型和服装结构的组合；
- 四视图须能验证正面、侧面和背面结构；
- 面部、关节、衣物与鞋履须适合后续绑定和动作；
- 资产事实与参考图优先于类型视觉语法；
- 基础图保持默认稳定状态。

### 严禁

- 不默认劳动者、返乡者、农民、儿童、萌娃或动物伙伴身份；
- 不默认晒黑、风霜、破衣、围裙、草帽、胶鞋、农具和作物；
- 不使用固定身高、固定头身比、固定男女面容、固定暖色或固定性别服装；
- 不出现剧情场景、动态劳动、手持道具、人物关系和可读品牌文字；
- 不附加与资产事实和视觉设计无关的技术控制语句。
