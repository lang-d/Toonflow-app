# 3D乡村漫剧视觉导演规划手册

## 一、应用边界与视觉定位

本手册负责把已确认的现代乡村生产生活事实转成可执行的三维卡通视觉方案，不决定剧情、经营方案、人物关系或资产事实。

只使用已确认的地域、季节、地貌、植被、生产对象、建筑、人员、动物、物件、天气、时段和行动。缺失时保持待确认，不自动加入：

- 暖黄丰收、金色田野、童话农场或文旅航拍；
- 破旧、贫困、苦难、统一乡愁滤镜；
- 作物、果筐、农具、牲畜、萌宠表演和丰收人群；
- 暴雨、灾损、泥污、受潮、磨损和成功经营结果。

三维卡通化用于提高轮廓、动作、材料状态和空间关系的可读性，不把真实生产空间改造成都市 3D 换背景，也不把一切表面做成光滑玩具。

本手册只给段落级色光、空间、机位覆盖、表演和声音方法；资产设定图与逐镜画面由各自阶段处理。

## 二、条件化色彩决策

色彩从场景事实推导，不使用固定色盘。

| 事实来源 | 决策方法 | 防止的问题 |
|---|---|---|
| 地貌与地表 | 让土、石、道路、水面或建筑基底形成低频主色 | 背景颜色过多抢夺劳动信息 |
| 植被与生产对象 | 只把事实存在的颜色作为区域或批次识别色 | 默认绿意、花海或金黄丰收 |
| 建筑与工作设施 | 用墙、瓦、砖、木、金属和塑料的本色划分功能区 | 所有空间变成同一暖色乡村 |
| 人物服装 | 保持资产颜色，必要时利用明度/冷暖与环境分离 | 为突出人物擅自换装或改色 |
| 商品与容器 | 让关键状态、批次或交接对象可识别 | 包装、商品和背景混成一片 |
| 天气与时段 | 调整整体明度、反差与空气层次 | 以滤镜代替真实光线变化 |

每个段落先确定：

1. 一个承担空间基底的主色关系；
2. 一个帮助区分人物、商品或工作位的辅助关系；
3. 仅在事实支持时使用的识别色。

颜色冲突时优先保证人物动作、商品状态和通行面可读，环境氛围让位。禁止用“高级、电影感、治愈、乡村感”作为色彩方案。

## 三、条件化光线与曝光

| 场景条件 | 光线方法 | 需要保留的可读信息 |
|---|---|---|
| 开阔日光 | 稳定太阳方向，卡通阴影边界清楚但不过硬 | 人物面部、手物接触、地面高低和道路方向 |
| 树冠或棚架筛光 | 将碎光概括为少量大形，不让斑点覆盖表情和操作 | 行走边界、抓握和商品表面状态 |
| 阴天漫射 | 降低反差，以色相和材质粗糙度分层 | 人物轮廓、工作区与潮湿/干燥差异 |
| 院坝半室外 | 协调室外亮面、檐下暗面和门洞过渡 | 入口出口、递交位置和人物进出 |
| 包装/储放空间 | 光源必须来自已确认门窗或灯具 | 台面、标签、开合、待处理/已处理区 |
| 晨昏 | 保留低角度方向与长影，但不自动金黄化 | 人物肤色、路线边界和关键物件 |
| 雨前后或湿地面 | 仅在事实存在时降低天空亮度、增加有限反射 | 通行面、湿滑边界和材料状态 |

曝光优先级固定为：

`人物判断与关键动作 → 商品/工具状态 → 交接位置与通行面 → 背景环境`

- 人物站在檐下而背景过亮时，先保住面部与手部动作，压低背景细节；
- 商品高光与人物肤色冲突时，控制商品高光面积，不让其变成发光塑料；
- 湿地或塑料反射只用于说明状态，不能覆盖脚下路线；
- 夜间仅使用剧本和场景资产中成立的光源，不凭空增加装饰灯和大片月光。

## 四、空间轴线与机位覆盖

导演规划先定义段落轴线和覆盖目的，不逐镜写分镜表。

| 轴线/机位组 | 叙事用途 | 覆盖与资产判断 |
|---|---|---|
| 生产轴线 | 人物与生产对象、工作面之间的操作关系 | 需看清正面工作位、侧向受力和对象去向 |
| 商品交接轴线 | 递出、接收、核验和保管 | 保持两人站位、物件移动方向和交接后的持有人 |
| 入口/出口轴线 | 进入、离开、等待、返回和受阻 | 门洞、院口、道路口反复承担行动时预划反向覆盖 |
| 道路轴线 | 人、车、商品跨区域移动 | 明确来向、去向、转弯点、停靠点和返回路线 |
| 工作位关系轴线 | 决定者、执行者、核验者和等待者的关系 | 关系位移需要同框、侧面或反向覆盖时提前规划 |
| 物件轴线 | 商品、容器、记录或工具成为判断中心 | 保持台面、手部、物件和人物脸部的稳定关系 |

### 机位选择

- **稳定机位**：呈现完整操作、多人协作和状态对照；
- **关系镜**：让决定、执行、递交、等待和核验处于同一空间；
- **跟随**：仅用于路线、携带物和交接过程需要持续可见的移动；
- **推近**：用于人物完成核验、作出选择或发现可见状态变化；
- **近距观察**：用于接触、开合、压痕、标签或材料变化；
- **远景**：只在需要建立区域连接、天气条件或道路方向时使用；
- **高位/航拍**：只有地理与路线无法由地面机位说明且事实支持时采用，不做旅游展示。

不使用无目的环绕、漂移、连续大幅运镜和夸张景深。镜头运动必须回答“需要持续看清哪项关系或状态”。

### 场景衍生资产预划

以下情况可在导演规划中标记场景衍生需求：

- 反向区域、门洞另一侧、工作台背面或道路转折反复承担行动；
- 同一地点的时段、天气、地面干湿、布置或开放状态发生已确认变化；
- 父场景不能稳定表现车辆停靠、商品交接或人物返回方向；
- 关键物件位置必须跨场次复用，而父场景没有该角度；
- 同一空间需要固定建立镜头和反向关系镜，且遮挡关系不同。

单次轻微推近、一次局部特写或父场景可覆盖的角度不需要新衍生资产。

## 五、卡通材质状态矩阵

卡通化保留大形、边缘、粗糙度和受力逻辑，不追求微观噪声。

| 材质 | 稳定表现 | 状态变化的可见依据 |
|---|---|---|
| 作物/商品 | 轮廓、表皮分区、体积和接触阴影清楚 | 压痕、切面、干湿或损耗仅按事实出现 |
| 土、石与道路 | 颗粒大形、裂缝方向、压实或松散区别 | 水分、车辙、脚印需有天气和接触来源 |
| 砖、瓦、混凝土 | 块面、接缝、边缘磨耗和重量感 | 受潮或破损不自动做旧 |
| 竹木 | 纤维方向、节点、连接和受力弯曲 | 开裂、磨损沿纹理和接触点发生 |
| 纸张/纸箱 | 壁厚、折边、压线、封口与挺度 | 受潮、压扁或撕裂沿边角和受力面传播 |
| 塑料 | 壁厚、注塑大形、有限高光和半透明边缘 | 变形、划痕和泥尘只影响接触区 |
| 金属 | 厚度、连接件、冷暖高光与重量 | 划痕、锈蚀和凹陷有暴露或受力来源 |
| 织物 | 层级、垂坠、折线和身体接触 | 湿度、泥点与磨损沿重力、边缘和摩擦区出现 |
| 植被与水分 | 以簇群和大形组织，不逐叶堆噪声 | 风向、雨水和时段改变轮廓与反射 |

同一场景中至少区分哑光、半哑光和有限反射表面，避免所有材质共享同一种塑料高光。

## 六、三维动画与表演

### 动作可行性

规划人物动作时明确：

- 重心在抬起、搬运、转身、停下和放置时如何转移；
- 手与把手、容器、工具或商品的接触点；
- 递交前后的抓握与换手；
- 衣物、头发和软质物件的惯性与停止余势；
- 物件重量、尺寸与人物动作幅度是否一致；
- 背面模型、袖口、裙摆、口袋或配件会不会遮挡、穿模或限制动作。

禁止无重力移动、突然换手、物件悬空、穿模、脚底滑行和没有接触点的搬运。

### 成人、儿童与动物

| 对象 | 表演重点 | 边界 |
|---|---|---|
| 成人 | 准备、检查、受力、分工、判断和收尾 | 不用夸张英雄姿势代替劳动 |
| 儿童 | 已确认安全区域内的观察、跟随、停顿和有限互动 | 视线高度、手可触范围与成人遮挡必须成立 |
| 动物 | 已确认活动区内的行走、嗅闻、回避和反应 | 保持物种运动与接触逻辑，不拟人化经营判断 |

儿童、动物、车辆和商品同场时，先规划安全距离、可见范围、移动路线和遮挡，再选择机位。制作安全只作为调度边界，不替代现场安全流程。

## 七、声音与空间层次

| 声音层 | 作用 | 规划方法 |
|---|---|---|
| 自然环境 | 建立时段、天气和区域开放度 | 风、虫鸟、水和树叶声须有方向与距离 |
| 生产操作 | 证明接触、受力、开合和状态 | 包装、工具、容器和材料声与动作同步 |
| 移动与交通 | 建立路线、接近、离开和停靠 | 脚步、车轮、发动机和地面材质对应 |
| 人物活动 | 建立协作距离和空间遮挡 | 交谈、呼喊和回应不越过不成立的遮挡 |
| 空间混响 | 区分开阔地、院坝、檐下、室内和道路 | 环境改变时同步改变声场，不靠配乐说明 |

声音不能自动添加不存在的动物、机器、车辆或人群，也不能用欢快音乐替代生产信息和人物关系。

## 八、视觉应用检查

- 色彩是否来自地域、材料、人物、商品、天气和时段事实，而非固定乡村色盘？
- 光线是否有成立的来源，并保住人物动作、商品状态和通行面？
- 生产、交接、入口出口、道路和关系轴线是否清楚？
- 机位变化是否服务状态、路线或关系，而非展示环境？
- 材质是否区分大形、粗糙度、接触和受力，且没有自动做旧？
- 人物、儿童、动物、车辆与道具的比例、接触、重心和遮挡是否可动画化？
- 是否预划了真正需要的反向、时段、天气或状态衍生资产？
- 声音是否具有来源、方向、距离和遮挡？

## 禁止项

- 禁止固定暖黄、丰收、治愈、贫困、童话农场和文旅宣传语法；
- 禁止默认作物、工具、牲畜、萌宠、泥污、灾损和经营结果；
- 禁止塑料玩具感、所有表面同高光、无重力动作、穿模和无接触搬运；
- 禁止逐镜图片 Prompt、四视图模板、渲染器、生成参数和平台专用语法。
