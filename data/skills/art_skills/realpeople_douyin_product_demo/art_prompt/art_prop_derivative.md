# 真人抖音商品实拍讲解 · 商品与道具衍生资产

## 职责与方法

`assetFoundation` 读取原商品、不可变外观锚点和本次确认变化；`visualDesignRationale` 只转译变化所涉及的部件、材料或状态。不得因为使用场景补造新功能、功效、包装文字、品牌或配件。

## 类型专属设计方法

锁定同一商品的轮廓、比例、包装、颜色、材料、确认标识范围和既有部件。本次只选择开合、装配、连接、已确认使用状态、可见余量或确认损耗中的一类变化；变化必须服从真实接缝、受力、容器和材料逻辑。

## 提示词模板（编译顺序）
```text
真人生活化商品实拍衍生设定图，same object as reference image，{本次唯一变化、确认条件}；锁定原商品轮廓、比例、包装、颜色、材料、可见标识范围和既有部件；显示变化相关的开合、连接或状态细节；正面 + 侧面 + 关键变化对照；中性可解释光线、浅灰背景；无人物手持、使用现场、虚构文字、品牌、参数、认证、价格、水印
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见造型、结构、布局、材质或状态结果。XML 写入 `<assetImagePrompt>`；最终图片提示词不得输出字段名、分析理由或占位符。

## 必守与严禁

必须保持同一商品，不换物、不新增功能，并只呈现一项确认变化。严禁把开合、使用或耗损扩展为虚构效果、促销结论或新配件。
