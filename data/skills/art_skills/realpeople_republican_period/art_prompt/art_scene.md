# 真人民国年代写实 · 场景基础资产

## 职责与方法

`assetFoundation` 读取地点、年代地域、固定布局、入口出口、功能区、地标、交通和基础设施；`visualDesignRationale` 负责识别度与可拍摄性。按确认类型组织街巷、车站、住宅、办公或公共空间，区分砖石、灰浆、木作、玻璃、金属和路面。招牌、车辆、电话、电线、灯具与装饰必须有事实来源。

## 类型专属设计方法

- 街巷从路幅、路面、建筑界面、门窗、排水与确认交通方式建立方向；招牌和电线等设施必须有年代事实。
- 车站先明确站台/候车区、轨道或道路方向、入口出口、检票和行李位置，不默认蒸汽火车、人群或告别场面。
- 住宅用院门、门厅、起居、卧室、服务空间和窗向中已确认部分建立公私层级；家具服从功能而非怀旧陈列。
- 办公及公共空间用接待、等候、工作、档案或会议区中已确认部分建立权限动线；文书、电讯和照明不得跨年代混搭。
- 年代识别优先依靠结构、制造工艺、交通通信条件与至少两个稳定地标，不依靠泛黄滤镜。

## 提示词模板（编译顺序）

```text
真人民国年代写实场景基础设定图，environment design sheet；{地点、年代地域、布局、入口出口、功能区、地标和确认基础设施}；建筑结构、街道交通、门窗楼梯、砖石木作玻璃金属与确认标识处于同一年代地域；单幅完整地点，前中后景、通行路线和出入口可读；确认时段天气下的窗光或现场动机光，真实材料响应；地点自然延伸；无人物剧情、符号拼贴、跨年代车辆技术、默认舞厅租界电台枪械、怀旧滤镜、文字水印。
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

XML 流程写入 `<assetImagePrompt>`，否则只返回提示词；不得残留占位项或新增地点、历史事件和设施。

## 必守与严禁

必须是无人物、可复用、空间关系可读的完整地点。严禁新增组织、交通工具、通信设备、招牌文字、谍战道具、旅游街景和跨年代基础设施。
