# 真人民国年代写实 · 角色衍生资产

## 职责与方法

`assetFoundation` 锁定基准面容、体态、发型结构、服装核心轮廓和年代锚点，并给出本次唯一变化；`visualDesignRationale` 说明变化如何符合面料、礼仪与年代。只改变确认的服装层、发型、配件、妆容、雨湿、尘土、伤病或磨损，不扩展剧情，不因谍战默认换装、血迹或武器。

## 类型专属设计方法

- 锁定骨相、五官比例、肤色、体态、发际线，以及基准服装的领口、门襟、腰线、衣长和鞋型。
- 把变化收敛为一个可见项目；雨湿使吸水面料局部变深、贴合并增加褶皱重量，灰尘停留在外露面与褶沟，磨损集中在事实指定的接触区。
- 伤病只影响确认部位的皮肤、包扎或衣料，不扩大成身份变化、奔逃姿态或整套服装重做。
- 四视图在相同部位、相同程度呈现唯一变化；参考图中的其他外形与年代锚点全部保持。

## 提示词模板（编译顺序）

```text
真人民国年代写实角色衍生设定图，same person as reference image；{基准人物面容、体态、发型、服装轮廓和年代锚点}；本次仅呈现{已确认单一服化或状态变化及限定部位}；变化符合对应年代服装结构、面料吸湿磨损、发型与配件固定方式；头像 + 正侧背全身四视图，同一人物且变化程度一致；中性自然窗光、真实皮肤织物；中性灰；不换人、不改身份体态、不增加第二变化、地点、组织、武器、跨年代元素、文字水印。
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

外层 XML 写入 `<assetImagePrompt>`，否则只返回最终提示词；不得残留占位项或扩大变化范围。

## 必守与严禁

必须声明同一人物、不可变锚点和唯一变化。严禁换人、改年龄体态、升级身份、添加配件武器、加入场景动作、跨年代造型或灾难化做旧。
