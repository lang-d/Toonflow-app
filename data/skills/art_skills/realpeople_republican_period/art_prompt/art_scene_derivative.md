# 真人民国年代写实 · 场景衍生资产

## 职责与方法

`assetFoundation` 锁定布局、入口、地标、建筑材料、交通与年代锚点，并指定唯一视角、景别、时段、天气或状态变化；`visualDesignRationale` 维持地点识别。变化只重算可见范围、光色、表面和已指定物件，不改变建筑、道路、年代或功能。

## 类型专属设计方法

- 视角或景别变化只重算可见面、遮挡和透视，不移动入口、道路、窗向、固定家具与基础设施。
- 时段变化只改变太阳方向、天空亮度、窗光和已确认人工光；天气变化按材料响应处理，雨改变反射与吸湿，雾只影响可见距离。
- 指定状态只能作用于明确物件或区域，不能用“戒严”“混乱”等宽泛词自动增加人群、路障、车辆或损坏。
- 至少用两个既有地标及相同入口、建筑轮廓或道路关系证明同一地点，年代锚点始终不变。

## 提示词模板（编译顺序）

```text
真人民国年代写实场景衍生设定图，same location；{基准地点布局、入口出口、地标、建筑材料、交通与年代锚点}；本次仅呈现{确认的视角、景别、时段、天气或状态}；只重算该变化造成的可见范围、阴影、灯光和材料响应；前中后景保持同一空间关系，以既有地标证明同一地点；可追溯现场光与真实年代材料；不越出地点边界；无空间重构、新设施、跨年代元素、人物剧情、第二变化、文字水印。
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

XML 流程写入 `<assetImagePrompt>`，否则只返回提示词；变化不明时保持基准场景。

## 必守与严禁

必须标明同一地点和唯一变化。严禁空间重构、新建筑、新设施、新人物、跨年代元素、额外天气状态和怀旧滤镜。
