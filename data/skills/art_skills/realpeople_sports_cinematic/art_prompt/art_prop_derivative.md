# 真人体育竞技写实 · 道具衍生资产

## 职责与方法

`assetFoundation` 锁定项目用途、尺寸、轮廓、结构、材料和标识，指定唯一角度、充放气、开合、湿润、泥污、磨损或损坏变化；`visualDesignRationale` 维持运动功能与材料因果。不得因使用状态改变规格、品牌或功能。

## 类型专属设计方法

- 充放气只改变确认气室的体积、表面张力和接触形态，不改变规格、阀门位置与用途。
- 湿润改变表面高光、色深和摩擦观感；泥污只附着在场地接触区；两者不能在未确认时同时出现。
- 磨损集中在握持、击打、承重、滚动或落地区；材料分别呈现起毛、划痕、压缩、掉漆或表层疲劳。
- 损坏必须有确认部位和物理因果，裂口、变形、断线或脱层不能同时扩散，也不能借损坏新增内部机关。
- 多视图保持项目用途、尺度、轮廓、结构、颜色和标识不变，并用局部特写证明唯一变化。


## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

XML 写入 `<assetImagePrompt>`，否则只返回提示词；无依据时保持基准。

## 必守与严禁

必须说明同一器材、唯一变化与材料因果。严禁换规格用途、同时充放气湿润泥污损坏、添加品牌赛事信息、人物使用、第二变化或无原因报废化。
