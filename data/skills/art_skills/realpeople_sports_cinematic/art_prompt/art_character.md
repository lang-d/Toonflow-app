# 真人体育竞技写实 · 角色基础资产

## 职责与方法

`assetFoundation` 读取身份、年龄段、面容、体态、发型、基础服装、确认运动服饰和锚点；`visualDesignRationale` 负责识别度、身体比例与动作可行性。体态只按确认事实，不由项目推导肌肉；服装说明层级、弹性、透气结构与鞋履，但不默认队服号码、护具、奖牌。基础状态无汗湿、泥污、疲劳和伤病。

## 类型专属设计方法

- 面容、肤色、骨相和身体比例来自人物事实，不由项目、位置或竞技水平推导肌肉量与英雄体型。
- 基础服装拆分贴身层、运动层、外套与鞋袜，说明弹性方向、透气区、接缝和活动余量；比赛服只有被确认才出现。
- 鞋履按确认运动环境表现鞋楦、鞋底接触面、固定方式和踝部关系；护具按事实说明覆盖区、绑带与关节活动范围。
- 基础状态保持干燥、清洁、无疲劳伤病和领奖语义，站姿只用于验证体态与装备可穿戴性。
- 头像和正侧背四视图保持体型、服装层级、鞋履、护具固定点和标线位置一致，不用运动动作掩盖结构。


## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

XML 写入 `<assetImagePrompt>`，否则只返回提示词；不得残留占位或新增项目、体态和装备。

## 必守与严禁

必须是稳定可复用的运动人物基础设定。严禁默认比赛服号码、护具器材、汗湿疲劳伤病、奖牌奖杯、广告肌肉、比赛动作和品牌文字。
