# 真人体育竞技写实 · 角色衍生资产

## 职责与方法

`assetFoundation` 锁定人物身份、面容、体态和服装轮廓，指定唯一比赛服、护具、发型、汗湿、泥污、伤病或赛后状态；`visualDesignRationale` 维持识别和材料因果。汗湿遵循接触与蒸发区域，泥污遵循场地接触，伤病只表现确认部位与限制；不得同时添加奖牌和胜负情绪。

## 类型专属设计方法

- 锁定人物骨相、体态、发型、基准服装轮廓和运动身份；比赛服、护具、汗湿、泥污或伤病各自是独立变化。
- “赛后状态”必须拆成一个可见项目，例如指定区域汗湿、指定接触面泥污、明确部位伤病或一套已确认比赛服，不编译胜负情绪。
- 汗湿根据皮肤蒸发区和织物吸湿扩散，泥污根据场地接触区，伤病只影响确认部位与活动限制。
- 比赛服或护具变化保持体态不变，并说明剪裁、弹性、绑带、覆盖和鞋履关系；不得附带号码、队徽与赞助标识。
- 四视图在相同部位、相同程度呈现唯一变化，其他基准锚点完全沿用参考图。

## 提示词模板（编译顺序）

```text
真人体育竞技写实角色衍生设定图，same person as reference image；{基准面容、体态、发型、服装轮廓与运动身份锚点}；本次仅呈现{确认的比赛服化、护具或身体状态及部位}；汗湿泥污伤病只在事实指定范围，织物皮肤发丝响应真实；头像 + 正侧背全身四视图，变化程度一致；中性窗光；中性灰；不换人改体态、不加第二变化、奖牌器材场景、品牌文字水印。
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

XML 写入 `<assetImagePrompt>`，否则只返回提示词；状态不完整时只保留确认部分。

## 必守与严禁

必须明确同一人物、唯一变化及部位。严禁改体态肌肉、加入第二状态、推导胜负情绪、奖牌器材场景、品牌号码或把赛后状态打包成多项变化。
