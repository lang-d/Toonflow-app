# 真人体育竞技写实 · 道具基础资产

## 职责与方法

`assetFoundation` 读取器材名称、项目用途、尺寸、重量感、轮廓、结构、材料、标识和状态；`visualDesignRationale` 负责握持/接触逻辑与识别度。表现皮革、复合材料、橡胶、织物、金属、木材和塑料中确认材料，不默认球具、护具、计时设备、号码或赛事品牌。

## 类型专属设计方法

- 先确定尺度、质量感与重心位置，再表现握持区、击打/承重/落地等实际接触面，不能用夸张造型牺牲功能。
- 皮革、复合材料、橡胶、织物、金属、木材和塑料只选确认材料，分别表现弹性、硬度、纹理、包覆和表面摩擦。
- 接缝、粘合、缝线、充气口、紧固件和可动连接必须符合受力与维护方式；没有事实时不添加电子模块。
- 护具需要说明人体覆盖区、弯折方向、绑带和缓冲层，道具本身仍以静置多视图呈现，不出现人物穿戴。
- 正侧背/底视图保持规格、轮廓、受力面、接缝和标识位置一致，以接触区特写验证材质。


## 输出规则

XML 写入 `<assetImagePrompt>`，否则只返回提示词；不得新增项目、功能和品牌。

## 必守与严禁

必须是完整、静置、规格和受力逻辑清楚的同一器材。严禁人物手持、比赛动作、默认球具护具计时设备、虚构功能、赛事号码品牌和广告产品图。
