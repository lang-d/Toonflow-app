# 角色衍生资产执行手册 · 真人都市写实

---

## 一、职责边界

角色衍生只改变“同一角色的可变视觉状态”，不能改写角色是谁。

默认保持：
- 父角色的身份、关系、年龄段、基础脸部身份识别和角色归属。
- 父角色基础图中的主要可识别锚点，例如脸部识别、常见穿搭逻辑、标志性配饰或习惯状态。
- `assetFoundation` 与 `visualDesignRationale` 中明确要求延续的事实和识别策略。

允许变化：
- 服装：校服、通勤装、居家装、工作服、正式服、剧情状态服装。
- 发型、发量、体态、气质和妆容：如果用户指令、剧情状态或衍生目的明确要求，可以变化。
- 配饰：眼镜、手表、发夹、围巾、腰带等穿戴类配饰。
- 表情与状态：仅当事实源明确要求时，可做可复用表情/状态图，例如疲惫、紧张、哭后、受伤后、雨后。

禁止变化：
- 新身份、新关系、新职业、新能力、新剧情经历。
- 换脸、换人、无依据改变年龄段或身份归属。
- 加入场景、手持道具、剧情动作、分镜镜头。

---

## 二、核心目标

角色衍生图必须同时满足：

1. **同一角色可识别**：图生图参考图负责身份一致性，提示词只补充必要变化，不重新描述整张脸。
2. **变化目标清楚**：只改变本次衍生需要改变的服装、妆容、发型、配饰或状态。
3. **可复用设定图**：仍是四视图/设定参考图，不是剧情画面。
4. **审美不降级**：保持真人都市写实、干净健康、上镜，不因“旧衣/疲惫/底层”自动变脏乱苦相。
5. **不污染生产阶段**：不把具体场景、动作、站位、镜头语言写进角色衍生资产。

---

## 三、视觉设计推导使用方式

`visualDesignRationale` 必须落实到角色衍生图中，尤其是：

- 衍生目的：这次变化服务什么，例如上学、通勤、家务、系统派单、正式会面、受挫后状态。
- 不可改事实：身份、关系、年龄段、角色归属，以及本次没有要求改变的父角色锚点。
- 可设计空间：服装款式、面料、颜色、妆容强度、发型/发量变化、体态变化、穿戴配饰、可见状态细节。
- 识别度策略：依赖父角色参考图保持同一人，只描述需要改变或强调的状态。
- 审美修正：避免无依据深灰黑塌缩、疲惫苦相、网红妆、证件照感、素人试衣照感；这些风险不要原样塞进最终 prompt。
- 最终视觉方案：明确四视图、变化项、服装层次、发型妆容、色彩和材质。

## 四、衍生类型执行方法

### 服装衍生

- 服装必须来自 `assetFoundation`、用户指令、参考包或剧情已确认需要。
- 默认由参考图保持父角色体态；如果衍生目标明确是长胖、消瘦、怀孕、受伤、疲惫、训练后等，可以描述体态变化。
- 旧衣、底层、劳动状态用洗旧、褪色、布料软塌、袖口磨损表达，不直接把“旧”翻译成脏乱或全黑。
- 重要角色服装要有具体角色依据，例如颜色、材质、版型、磨损或穿戴习惯。

### 发型与妆容衍生

- 发型可以整理、束起、放下、剪短、变凌乱；发量和发色也可以在事实源或用户指令明确时变化。
- 妆容不是默认必需项；只有用户指令或衍生目的需要时才增加。
- 妆容应服务角色状态：日常可素净，正式可轻妆，疲惫可通过眼下暗沉和发丝松散表达。
- 禁止网红妆、强妆容、过度磨皮、改变脸部结构。

### 表情与状态衍生

- 只做“可复用状态设定图”，不做具体剧情瞬间。
- 可表现疲惫、紧张、哭后、受伤后、雨后、工作后、发福、消瘦、病后、成长后等状态，但必须仍是同一角色。
- 状态细节要克制：轻微眼眶泛红、衣领皱褶、发丝松散、袖口污渍等，不把角色做成不可辨认。

### 配饰衍生

- 只允许穿戴类配饰：眼镜、手表、发夹、围巾、腰带、耳饰、项链。
- 手持物、包、手机、钥匙、文件夹、酒杯等属于道具或剧情交互，默认不进入角色衍生图。
- 若配饰来自角色核心事实，例如旧电子手表，应保持形态、位置和磨损特征一致。

## 五、变化分层与决策参考

以下内容用于帮助模型把衍生目标拆成可控变化层。它们是决策参考，不要求每一层都输出；没有明确变化需求的层应省略或保持参考图状态。

| 层级 | 内容 | 使用方式 |
|---|---|---|
| L0 | 父角色参考图 | 通过图生图保持同一人物，不在提示词里复述整张脸 |
| L1 | 妆容/面部状态 | 只有用户指令、状态或场合需要时才写 |
| L2 | 发型/发量 | 可写束发、披发、剪短、凌乱、发量变化等明确变化 |
| L3 | 内搭/基础衣层 | 写颜色、面料、领口、袖口、磨损或整洁度 |
| L4 | 外衣/主服 | 写款式、版型、材质、职业/场合依据 |
| L5 | 穿戴配饰 | 只写眼镜、手表、发夹、围巾、腰带、耳饰、项链等穿戴类 |
| L6 | 可复用状态 | 疲惫、哭后、病后、受伤后、雨后、发福、消瘦等 |

### 妆容强度决策

| 线索 | 决策 |
|---|---|
| 仅换装、换发型、换状态，未要求面部修饰 | 不强制妆造，可保持自然干净 |
| 气色提亮、精神饱满、自然微笑 | 轻妆或自然气色修饰 |
| 商务、正式会面、重要活动 | 受控正式妆或清爽职业妆 |
| 疲惫、哭后、病后、受挫 | 不做精致妆；用眼下暗沉、眼眶泛红、发丝松散等状态细节 |
| 派对、舞台、强妆容 | 只有用户明确要求时才使用，避免网红妆和换脸感 |

### 线索过滤

- 场景词只用于理解衍生目的，不能写成背景环境。
- 道具词不能自动变成手持物；手表、眼镜、发夹等穿戴类除外。
- 动作词不能自动变成姿态动作；本手册默认仍输出可复用设定图。
- 服装、妆容、发型、体态、状态必须来自用户指令、事实源或 `visualDesignRationale`，不要为了“丰富”而加无关变化。

### 直接润色接口输出约束

- 如果外层流程要求 XML，必须服从外层 XML 输出格式。
- 如果本手册被旧的 prompt 润色接口直接调用，只输出最终提示词文本，不输出表格、分析、分层方案、解释或 Markdown 标题。

## 六、摄影与画面参数

| 项目 | 执行要求 | 提示词参考 |
|---|---|---|
| 图像类型 | 角色衍生设定图 / 四视图，不是剧情画面 | character derivative design sheet, character turnaround |
| 参考关系 | 基于父角色参考图保持同一人物；提示词不要重复描述整张脸 | same person as reference image |
| 人像特写 | 85mm portrait reference，正面平视，面部正对镜头，双眼同高，鼻梁居中，保留脸部识别度；禁止微侧脸、三分之二侧脸、回头视角 | 85mm front-facing portrait closeup, straight-on face, looking at camera, centered nose bridge, symmetrical eyes, no three-quarter view, no side profile |
| 全身视图 | 50mm full-body studio reference，正面/侧面/背面统一比例 | 50mm full body reference |
| 光线 | 5600K 柔光箱 + 双侧弱补光，避免证件照硬光 | 5600K softbox lighting, soft fill light |
| 背景 | 纯净中性灰 #E8E8E8，不出现生活场景 | seamless neutral gray background #E8E8E8 |
| 画面 | 正面头像特写 + 正面全身 + 侧面全身 + 背面全身；头像特写必须正面直视，不微侧 | front-facing portrait closeup, straight-on face, front view, side view, back view |

```text
真人都市写实角色衍生设定图，character derivative design sheet，character turnaround，

左至右并排：85mm front-facing portrait closeup, straight-on face, looking at camera, no three-quarter view + 50mm front full body + 50mm side full body + 50mm back full body，

no scene，no action pose，no handheld object，no readable text，no watermark
```

## 八、必守与严禁

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是同一角色的衍生设定图，不是新角色 |
| R2 | 必须基于父角色参考图保持同一人物；不要无依据重写面容 |
| R3 | 必须落实 `assetFoundation` 的事实锚点 |
| R4 | 必须落实 `visualDesignRationale` 的衍生目的、识别度策略和审美修正 |
| R5 | 必须包含头像特写、正面全身、侧面全身、背面全身 |
| R6 | 头像特写必须是正面特写：面部正对镜头，双眼同高，鼻梁居中，不得微侧、三分之二侧脸、侧脸或回头 |
| R7 | 必须完整头到脚，不裁切头顶、脚部、手部 |
| R8 | 变化必须集中在服装、发型、妆容、穿戴配饰或可复用状态 |
| R9 | 服装色彩、体态、发型、发量变化必须有事实源、用户指令或衍生目的依据 |

### 严禁

| 编号 | 禁止项 |
|---|---|
| X1 | 换脸、换人、无依据改年龄段、改身份关系 |
| X2 | 场景背景、室内外环境、天气、分镜镜头 |
| X3 | 行走、奔跑、回眸、举手、低头等剧情动作姿态 |
| X4 | 手机、钥匙、包、文件、酒杯等手持物或交互道具 |
| X5 | 无依据强妆容、网红脸、过度磨皮、蜡像皮肤 |
| X6 | 把内部审美规则原样写进最终提示词，例如“不无依据默认灰黑” |
| X7 | 四视图间面容、发型、服装或状态不一致 |
| X8 | 把疲惫、底层、旧衣自动处理成脏乱、苦相或不可辨认 |
| X9 | 头像特写使用微侧脸、三分之二侧脸、侧脸、回头、低头或仰头角度 |
