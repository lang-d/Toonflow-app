# 道具基础设定图执行手册 · 真人都市写实

---

## 一、职责边界

本手册只决定“道具怎么表现”，不决定“道具在剧情里发生了什么”。

允许决定：
- 道具设定图的视角、摆放、光线、材质、比例和细节展示。
- 如何把 `assetFoundation` 与 `visualDesignRationale` 转译成稳定可复用的道具图。
- 如何表达使用痕迹、年代感、廉价感、珍贵感或角色归属感。

禁止决定：
- 新剧情用途、新能力、新品牌、新世界规则。
- 参考包、基础设定或用户指令里没有的角色关系。
- 把道具图写成电商广告、剧情现场、手持使用画面或产品海报。

---

## 二、核心目标

道具基础图必须同时满足：

1. **功能可读**：观众一眼知道道具是什么、怎么用。
2. **形态稳定**：轮廓、尺寸、结构、关键标识可在后续衍生中保持一致。
3. **材质真实**：金属、塑料、布料、皮革、玻璃、橡胶等材质清晰可信。
4. **归属可见**：如果道具和角色或剧情有关，要通过磨损、贴纸、颜色、改装、收纳痕迹体现。
5. **独立展示**：基础图只展示道具本体，不出现人物、手、穿戴状态或正在使用状态。

---

## 三、视觉设计推导使用方式

`visualDesignRationale` 必须落实到道具图中，尤其是：

- 叙事功能：道具在故事中提供什么信息，例如通勤、贫旧、家庭劳动、系统派单、隐秘证据。
- 不可改事实：道具名称、用途、核心形态、真实材质、已有标识或磨损。
- 可设计空间：可以补充的颜色、贴纸、划痕、磨损位置、比例、附件、收纳状态。
- 识别度策略：选择 3-5 个后续可复用的视觉锚点，例如裂纹表盘、褪色表带、蓝色塑料筐、旧车把胶套。
- 审美修正：避免电商新品感，避免过度脏乱，避免所有道具都黑灰金属。
- 最终视觉方案：明确主视图、辅助视图、材质细节和背景。

## 四、设定图摄影参数

| 项目 | 执行要求 | 提示词参考 |
|---|---|---|
| 图像类型 | 道具设定图 / 物件参考图，不是广告图 | prop design sheet, object reference sheet |
| 视图 | 主视图 + 侧视图 + 背面/底部 + 材质细节特写 | front view, side view, back view, detail closeup |
| 焦段 | 70mm-100mm product reference，避免广角变形 | 85mm product reference lens |
| 光线 | 5600K 柔光箱 + 弱补光，保留材质高光和细小划痕 | 5600K softbox lighting, soft fill light |
| 背景 | 中性灰无缝背景 #E8E8E8，允许轻微接触阴影 | seamless neutral gray background |
| 比例 | 道具占画面主体 65%-80%，形态完整，不裁切关键结构 | full object, no cropped edges |
| 人物 | 禁止人物、手、手指、人体局部、穿戴/握持状态 | no hands, no people, not held, not worn |

## 五、道具类型执行方法

### 电子产品与系统相关物

- 重点展示屏幕、按键、接口、边框磨损、贴纸、保护壳、裂纹或油光。
- 旧设备不等于完全坏掉；通过边角磨损、表面细划痕、屏幕指纹、褪色保护套表达。
- 不无依据生成真实品牌 logo；需要标识时用无文字符号或抽象标签。

### 个人饰品与穿戴物

- 基础图展示道具本体，不穿戴在角色身上。
- 手表、眼镜、发卡、项链要展示正面、侧面、背面和关键材质特写。
- 使用痕迹要服务角色：廉价、长期佩戴、被珍惜、维修过，都要有不同表达。

### 生活用品与工具

- 重点展示用途、握持区域、开关、磨损、污渍位置和真实材质。
- 旧三轮车、塑料筐、饭盒、钥匙串等要有生活痕迹，但保持轮廓清楚。
- 避免产品广告式高亮，也避免把道具变成废品堆。

### 交通与大型道具

- 可以用单张三视图或主视图 + 局部特写。
- 必须展示轮廓比例、轮子/把手/座椅/货架/灯具等固定结构。
- 使用痕迹以轮胎磨损、车把胶套、金属掉漆、贴纸残留等表达。

### 办公文具与纸张类

- 重点展示纸张边角、折痕、标签、夹子、笔帽、装订和使用痕迹。
- 文件、票据、书签等不应出现可读文字；需要标识时使用抽象符号或模糊标签。
- 纸张旧化可用泛黄、折角、压痕、胶带痕，不要自动变成秘密证据或剧情线索。

### 类型速查

| 类型 | 关键结构 | 细节参考 |
|---|---|---|
| 电子产品 | 屏幕、按键、接口、保护壳、边框 | 指纹、裂纹、贴纸、细划痕 |
| 饰品/穿戴物 | 表盘、镜框、链条、扣具、表带 | 磨亮、褪色、折痕、局部划痕 |
| 生活用品 | 开关、把手、盖子、容器边缘 | 污渍、水痕、磨损、油光 |
| 办公文具 | 笔帽、夹子、装订、纸张边角 | 折角、压痕、泛黄、胶带痕 |
| 交通/大型道具 | 轮子、车把、座椅、货架、灯具 | 掉漆、泥点、轮胎磨损、贴纸残留 |

## 六、材质与使用痕迹

| 材质 | 表现方法 |
|---|---|
| 金属 | 细划痕、边角掉漆、轻微氧化、冷暖高光 |
| 塑料 | 褪色、细小划痕、油光、廉价注塑边缘 |
| 玻璃 | 指纹、反光、裂纹、边缘厚度 |
| 橡胶 | 磨亮、开裂、灰尘附着、握持痕迹 |
| 皮革 | 折痕、边缘磨损、局部变色 |
| 布料 | 纤维、褪色、缝线、起球和边缘磨损 |
| 纸张 | 折角、压痕、旧胶带痕、泛黄 |

## 七、多视图设定图参考

| 视图 | 用途 |
|---|---|
| 主视图 | 展示道具最可识别的轮廓和用途 |
| 侧面 | 展示厚度、结构层次、握持区域或连接件 |
| 背面/底部 | 展示固定结构、背部标识、底座、接口或磨损 |
| 材质细节特写 | 展示划痕、纤维、裂纹、贴纸、金属氧化或屏幕反光 |

多视图是为了稳定后续生成，不是商品广告排版。大型道具可以用主视图加局部特写替代严格 2x2 网格。

## 九、必守与严禁

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是道具设定图，不是剧情使用画面 |
| R2 | 必须落实 `assetFoundation` 的用途、形态、材质和固定标识 |
| R3 | 必须落实 `visualDesignRationale` 的识别度策略和审美修正 |
| R4 | 必须展示完整道具轮廓和关键结构 |
| R5 | 必须展示至少一个材质或磨损细节 |
| R6 | 必须无人物、无手、无穿戴、无握持 |

### 严禁

| 编号 | 禁止项 |
|---|---|
| X1 | 人物、手、手指、人体局部、穿戴状态 |
| X2 | 电商广告图、品牌海报、过度新品感 |
| X3 | 无依据真实品牌 logo 或可读文字 |
| X4 | 过度脏乱导致道具形态不可读 |
| X5 | 新增基础设定里没有的剧情能力或隐藏功能 |
| X6 | 3D render、CG、游戏道具、卡通质感 |
