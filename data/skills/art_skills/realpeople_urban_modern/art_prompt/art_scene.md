# 场景基础设定图执行手册 · 真人都市写实

---

## 一、职责边界

本手册只决定“场景怎么表现”，不决定“剧情发生了什么”。

允许决定：
- 场景设定图的视角、焦段、光线、色彩、空间层次和材质表现。
- 如何把 `assetFoundation` 与 `visualDesignRationale` 转译成稳定可复用的场景主视图。
- 如何让空间功能、固定布局、关键物件、时代痕迹和生活痕迹可读。

禁止决定：
- 新地点、新剧情事件、新人物关系、新世界规则。
- 参考包或基础设定里没有的核心空间功能。
- 把场景图写成分镜画面、剧情现场、电影海报或氛围概念图。

---

## 二、核心目标

场景基础图必须同时满足：

1. **空间可复用**：观众能看清入口、出口、主体区域、动线和关键物件。
2. **功能可读**：一眼能知道这是居家、学校、菜市场、走廊、楼道、电梯间等哪类空间。
3. **连续性稳定**：固定布局、墙面、地面、主要家具、招牌、门窗和关键道具可在后续镜头复用。
4. **真实但有设计**：保持都市写实，不做脏乱堆砌；贫旧、拥挤、日常感通过材质和使用痕迹表达。
5. **不剧情化**：基础图不出现人物，不表现正在发生的事件，不把场景变成某一集的镜头。

---

## 三、视觉设计推导使用方式

`visualDesignRationale` 必须落实到场景图中，尤其是：

- 叙事功能：这个空间在故事里承担什么功能，例如压迫、通勤、家庭劳动、临时歇脚、社区流动。
- 不可改事实：场景名称、空间类型、固定布局、关键物件、默认时间/状态。
- 可设计空间：可以补充的墙面材质、地面磨损、收纳方式、灯具、标识、背景层次。
- 识别度策略：选择 3-5 个后续可复用的视觉锚点，例如红色塑料凳、贴纸冰箱、旧电梯按钮、菜摊蓝色遮雨棚。
- 审美修正：避免空泛“电影感”，避免全场灰黑，避免过度破败或脏乱。
- 最终视觉方案：明确主视角、焦段、主色域、光源和空间层次。

## 四、摄影与构图参数

| 项目 | 执行要求 | 提示词参考 |
|---|---|---|
| 图像类型 | 可复用场景设定图，不是分镜画面 | environment design sheet, location reference photo |
| 主视角 | 选择最能代表空间功能的单一主视图 | representative angle, hero location view |
| 焦段 | 室内 24mm-28mm，狭窄空间可 24mm；室外 28mm-35mm，避免夸张广角畸变 | 24mm interior lens / 35mm street photography |
| 视线高度 | 默认人眼高度 1.45m-1.6m，特殊空间可轻微俯视展示布局 | eye-level camera, natural observer height |
| 光线 | 遵守场景事实；室内以窗光、顶灯、台灯、冷白灯为主；室外以自然光和城市环境光为主 | natural window light, cool fluorescent ceiling light |
| 色彩 | 从场景功能和项目色卡中选低饱和识别色 | restrained urban palette with identifiable accent color |
| 人物 | 基础场景图禁止出现人物、人影、人体轮廓 | no people, no characters, no human figures |
| 画面 | 单画面，不拼图，不分屏，不多视图网格 | single image, no split screen |

## 五、场景类型执行方法

### 居家空间

- 重点展示生活动线、收纳状态、餐桌/沙发/床/厨房等功能区。
- 贫旧或压力感通过物件密度、旧家具、墙面轻微污痕、便宜灯具表达，不等于脏乱废墟。
- 色彩可用旧白、浅木色、淡蓝塑料、米灰墙面、局部暖色小物，避免全屋灰黑。

### 学校与公共机构

- 重点展示制度感和可复用标识：走廊、门牌、公告栏、栏杆、操场边界、办公室布局。
- 光线可偏冷白，但要保留真实空气感，不做医院恐怖片式冷青。
- 地面、墙面和标识要清楚，方便后续分镜复用。

### 街道、菜市场、社区空间

- 重点展示摊位、招牌、地面、遮雨棚、电线、临时收纳、交通动线。
- 允许生活痕迹和杂物，但要有组织，不把画面变成不可读的杂乱堆。
- 色彩要有城市生活识别色，例如蓝色遮雨棚、红色塑料筐、绿色菜摊、旧黄路灯。

### 楼道、电梯、走廊

- 重点展示空间纵深、门、电梯按钮、楼层标识、墙面磨损、灯光来源。
- 焦段不要过度夸张，避免变成恐怖片或游戏关卡。
- 如果空间狭窄，使用 24mm 并保持垂直线稳定。

### 办公与商业空间

- 办公空间重点展示工位、电脑、文件、白板、绿植、隔断和秩序感。
- 商业空间重点展示门头、货架、收银台、广告牌、灯箱和顾客动线，但基础图不出现人物。
- 酒店、咖啡店、商场等空间可以更整洁，但仍要有真实使用痕迹，避免样板间或广告图。

### 类型速查

| 类型 | 可复用锚点 | 注意事项 |
|---|---|---|
| 居家 | 餐桌、沙发、厨房、收纳、旧家具 | 日常感不等于脏乱 |
| 学校/机构 | 门牌、公告栏、栏杆、走廊、操场边界 | 冷白光可用，但避免恐怖片化 |
| 菜市场/社区 | 摊位、遮雨棚、塑料筐、地面水迹、招牌 | 杂物要有组织，不能不可读 |
| 楼道/电梯 | 楼层标识、电梯按钮、门、墙面磨损 | 保持垂直线稳定 |
| 办公/商业 | 工位、货架、收银台、灯箱、动线 | 不做广告海报感 |

## 六、材质与使用痕迹

| 材质 | 表现方法 |
|---|---|
| 墙面 | 轻微污痕、补漆、贴纸残留、公告胶痕，不能无依据大面积破败 |
| 地面 | 踩踏磨损、水渍反光、旧瓷砖缝、菜市场湿润地面 |
| 金属 | 电梯按钮磨亮、栏杆划痕、铁门掉漆、轻微氧化 |
| 玻璃 | 手印、反光、贴纸、轻微灰尘 |
| 木材 | 桌角磨损、旧木纹、廉价贴皮边缘翘起 |
| 塑料 | 低价生活用品的轻微褪色、划痕和使用痕迹 |

## 七、环境条件参考

以下内容只用于视觉转译，不能新增剧情事件或改变场景事实。

| 条件 | 表现方式 |
|---|---|
| 清晨 | 柔和低角度光、轻微冷暖交界、薄雾感可选 |
| 正午 | 光线更直接、阴影短、整体明亮 |
| 黄昏 | 暖色边光、长阴影、局部金色反光 |
| 夜晚 | 室内灯、路灯、招牌光或电梯冷白灯成为主要光源 |
| 阴天 | 阴影柔和、饱和度略低、空气更平 |
| 细雨/雨后 | 地面湿润反光、水渍、雨棚滴水、玻璃水痕 |
| 空气透视 | 室外远景略灰蓝、边缘对比降低 |
| 季节 | 植被、衣物、广告、地面状态与季节一致 |

## 九、必守与严禁

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是场景基础设定图，不是剧情分镜 |
| R2 | 必须落实 `assetFoundation` 的空间事实和固定物件 |
| R3 | 必须落实 `visualDesignRationale` 的识别度策略和审美修正 |
| R4 | 必须展示前/中/后景或清晰空间纵深 |
| R5 | 必须明确光源逻辑和主要材质 |
| R6 | 必须无人物、无人影、无人体轮廓 |

### 严禁

| 编号 | 禁止项 |
|---|---|
| X1 | 人物、手、影子、背影、人体剪影 |
| X2 | 多视图拼图、分屏、网格布局 |
| X3 | 把基础场景做成某个剧情动作瞬间 |
| X4 | 无依据全场灰黑、过度破败、恐怖片化 |
| X5 | 3D render、CG、游戏引擎、卡通质感 |
| X6 | 新增参考包、基础设定和用户指令里没有的地点功能 |
