# 道具衍生资产执行手册 · 真人都市写实

---

## 一、职责边界

道具衍生只改变“同一道具的状态、角度、磨损程度或局部细节”，不能改写道具是什么。

必须保持：
- 道具核心用途、轮廓、结构、主要材质。
- `assetFoundation` 和基准图中的标识、颜色、尺寸关系、归属痕迹。
- `visualDesignRationale` 中确定的识别度策略。

允许变化：
- 角度：正面、侧面、背面、底部、局部特写。
- 状态：崭新、日常使用、陈旧、轻微损坏、维修后。
- 细节：划痕、褪色、指纹、污渍、贴纸残留、磨损位置。

禁止变化：
- 新增剧情功能、隐藏能力、真实品牌 logo。
- 改变道具类型，例如把电子手表变成智能手机。
- 出现人物、手、穿戴或握持状态，除非调用方明确要求。

---

## 二、衍生原则

1. **轮廓锁定**：核心外形必须一眼认出是同一道具。
2. **结构锁定**：按钮、表带、轮子、把手、接口、盖子等固定结构不能消失。
3. **状态可读**：损坏、陈旧、湿润、维修等状态要清楚但不过度。
4. **材质合理**：磨损和损坏必须符合材质物理逻辑。
5. **独立展示**：默认仍是道具静物，不出现人物和使用场景。

## 三、常用状态变化

| 状态 | 表现方法 |
|---|---|
| 崭新 | 结构完整、表面干净、光泽自然，但不做电商广告感 |
| 日常使用 | 轻微划痕、指纹、边角磨亮、局部油光 |
| 陈旧 | 褪色、表面磨损、胶边老化、布料起球 |
| 微损 | 小划痕、小凹痕、轻微掉漆，不影响识别 |
| 破损 | 裂纹、缺口、明显掉漆或变形，但核心结构仍清楚 |
| 轻微损坏 | 小裂纹、掉漆、凹痕、松动但仍可识别 |
| 屏幕破损 | 裂纹、黑斑、边角碎裂或保护膜翘起，不新增屏幕内容 |
| 维修后 | 胶带、替换零件、补漆、简单固定痕迹 |
| 污渍/泥点 | 局部污渍、泥点、水渍，不把整体糊成不可读 |
| 雨后/潮湿 | 水珠、湿润反光、局部泥点，不能把结构糊掉 |

状态变化必须符合材质物理逻辑。金属可掉漆、划痕、氧化；塑料可褪色、裂纹、油光；布料可起球、褪色、污渍；玻璃可反光、裂纹、指纹。

## 五、必守与严禁

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须保持同一道具的核心轮廓和结构 |
| R2 | 必须保持基础材质和识别锚点 |
| R3 | 状态变化必须符合物理逻辑 |
| R4 | 默认必须无人物、无手、无穿戴、无握持 |

### 严禁

| 编号 | 禁止项 |
|---|---|
| X1 | 把道具变成另一种物品 |
| X2 | 新增剧情功能、隐藏能力或真实品牌 |
| X3 | 人物、手、穿戴、握持状态 |
| X4 | 过度损坏导致不可识别 |
| X5 | 电商广告图、品牌宣传图 |
| X6 | 3D render、CG、游戏道具质感 |
