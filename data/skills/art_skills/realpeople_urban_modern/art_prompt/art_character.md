# 角色基础设定图执行手册 · 真人都市写实

---

## 一、职责边界

本手册只决定“怎么画”，不决定“角色是谁”。

允许决定：

- 摄影参考、焦段、光线、背景、画面布局。
- 面部、体态、服装、材质、色彩如何被表现得稳定且上镜。
- 如何让角色符合设定，并且具有美感和观众缘。

禁止决定：

- 角色身份、关系、职业、能力、世界规则、剧情功能。
- 参考包或基础设定中没有的新人物、新地点、新剧情经历。

---

## 二、核心目标

角色基础图必须同时满足：

1. **设定稳定**：面容、发型、体态、基础服装在四视图中一致。
2. **真实但上镜**：保留真人质感，但整体干净健康、亲和、有观众缘。
3. **角色有记忆点**：从角色事实中提炼 3-5 个可复用视觉锚点。
4. **可供后续衍生**：基础服装不复杂，但要有角色识别色和材质特征。

---

## 三、摄影执行参数

| 项目 | 执行要求 | 提示词参考 |
|---|---|---|
| 图像类型 | 角色设定图 / 四视图 / 设计参考，不是剧情画面 | character design sheet, character turnaround |
| 人像特写 | 85mm portrait reference，正面平视，面部正对镜头，双眼同高，鼻梁居中，左右脸轮廓基本对称，禁止微侧脸、三分之二侧脸、回头视角 | 85mm front-facing portrait closeup, straight-on face, looking at camera, centered nose bridge, symmetrical eyes, no three-quarter view, no side profile |
| 全身视图 | 50mm full-body studio reference，正面/侧面/背面统一比例 | 50mm full body reference |
| 光线 | 5600K 柔光箱 + 双侧弱补光，阴影柔和但保留面部结构 | 5600K softbox lighting, soft fill light |
| 背景 | 纯净中性灰无缝背景，不出现生活场景 | seamless neutral gray background #E8E8E8 |
| 皮肤 | 真实皮肤纹理，整体干净健康，避免过度磨皮和疲态 | natural skin texture, clean healthy skin |
| 画面 | 头顶到脚底完整，不裁切头顶、脚部、手部 | head-to-toe full body, no cropping |

## 四、面容与观众缘

### 面容设计原则

- 不预设固定脸型模板，由 `assetFoundation` 和 `visualDesignRationale` 推导差异化五官。
- 必须输出可复用面部锚点：脸型、眉眼、鼻嘴、下颌、颧骨或额头特征。
- 真实但上镜：眼神清楚、有精神，脸部干净，肤色健康。
- 主角或需要观众共情的重要角色要有亲和度；压迫型角色也要有记忆点但不强行亲和

### 可用表达

| 目标 | 推荐表达 |
|---|---|
| 真实 | natural skin texture, subtle pores, realistic facial structure |
| 上镜 | camera-friendly face, clean healthy complexion |
| 亲和 | approachable expression, soft focused eyes |
| 克制 | calm neutral micro-expression, restrained but vivid |
| 观察力 | focused reading gaze, alert eyes without fantasy effects |

### 避免表达

- tired face, sickly look, dull eyes, harsh ID-photo lighting。
- dirty, messy, gloomy, miserable，除非角色事实明确要求。
- 过度美颜、网红脸、强妆容、夸张表情。

## 五、服装与色彩决策

### 决策顺序

1. 先遵守 `assetFoundation` 的身份、阶层、年龄、职业、默认服装事实。
2. 再遵守 `visualDesignRationale` 的识别度策略和审美修正。
3. 最后从项目色卡中选择低饱和但有辨识度的角色色。

### 推荐色域，不是硬锁

低饱和角色色可参考：

- 米白、旧白、浅蓝、浅灰蓝、雾蓝。
- 旧浅卡其、浅棕、淡豆绿、柔和雾粉。
- 褪色牛仔蓝、深藏青、暖灰米。


### 基础服装方向

| 角色状态 | 默认方向 |
|---|---|
| 学生 | 校服、学院装、干净运动外套 |
| 上班族 | 衬衫、针织衫、西装外套、简洁通勤装 |
| 居家/休闲 | T 恤、针织衫、牛仔裤、棉麻外套 |
| 底层但干净 | 洗旧浅色上衣、朴素外套、褪色牛仔、旧但整洁的鞋 |
| 特殊职业 | 对应职业基础服装，保持写实和安全 |

## 六、可画执行参考

以下内容只作为事实不足时的视觉补全候选，用于帮助生成可画、稳定的设定图。它们不是事实源，不能反向决定角色身份、职业、关系、能力或剧情功能。

### 肤感与上镜状态

| 项目 | 参考方向 |
|---|---|
| 肤色 | 自然肤色，允许偏白、偏黄或小麦色，但全身肤色要统一 |
| 质感 | 保留真实皮肤纹理和轻微毛孔，不做蜡像磨皮 |
| 状态 | 干净健康，有精神；疲惫、病态、脏乱只在事实源明确要求时表现 |
| 光泽 | 自然光泽，不油腻、不哑光塑料感 |

### 体态与比例

| 项目 | 参考方向 |
|---|---|
| 身高段 | 可写高/中等/偏矮，或使用已有年龄、职业、初始描述推导 |
| 头身比 | 真人写实比例，默认约 7-8 头身，不追求超模化 |
| 肩颈 | 肩颈自然，姿态舒展，避免僵硬证件照感 |
| 手部 | 手型自然、指节正常、手部完整，不裁切 |
| 站姿 | 自然站立，双臂下垂，服务四视图稳定 |

### 发型与发量

| 项目 | 参考方向 |
|---|---|
| 发色 | 默认自然黑、深棕或事实源指定发色 |
| 发长 | 短发、齐肩、及肩、长发、低马尾等按事实源或视觉推导选择 |
| 发量 | 明确浓密、普通、稀疏、贴头皮等可画状态 |
| 发质 | 发丝清晰，真实自然，不做塑料头发 |
| 发饰 | 基础图默认少用；只有事实源或识别策略需要时加入 |

### 基础服装参考

| 角色线索 | 可参考方向 |
|---|---|
| 学生 | 校服、学院装、干净运动外套、帆布鞋 |
| 上班族 | 衬衫、针织衫、西装外套、简洁通勤装 |
| 居家/休闲 | T 恤、针织衫、牛仔裤、棉麻外套 |
| 底层但干净 | 洗旧浅色上衣、朴素外套、褪色牛仔、旧但整洁的鞋 |
| 特殊职业 | 对应职业基础服装，但保持写实、合身、安全 |

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 面部占 60%+，头顶到锁骨完整展示；面部必须正对镜头，双眼同高，鼻梁居中，不能微侧 | front-facing portrait closeup, straight-on face, looking at camera, centered nose bridge, no three-quarter view |
| 左二 | 正视图 | 正面 0° | 全身立像 | 面对镜头，双臂自然，从头顶到脚底完整展示 | front view, full body head to toe |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰，从头顶到脚底完整展示 | side view, profile, full body |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑、背部、发尾、脚部清晰 | back view, rear view, full body |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 纯净中性灰 #E8E8E8 |
| 站姿 | 自然站立，双脚平行微分，双臂自然下垂 |
| 光线 | 5600K 柔光箱 + 双侧弱补光，无硬阴影 |
| 一致性 | 四视图肤色、体型、发型、面容、基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、必守与严禁

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是角色设定图，不是剧情画面 |
| R2 | 必须包含人像特写、正面全身、侧面全身、背面全身 |
| R3 | 人像特写必须是正面特写：面部正对镜头，双眼同高，鼻梁居中，不得微侧、三分之二侧脸、侧脸或回头 |
| R4 | 必须完整头到脚，不裁切头顶、脚部、手部 |
| R5 | 必须落实 `assetFoundation` 的事实锚点 |
| R6 | 必须落实 `visualDesignRationale` 的识别度策略和审美修正 |
| R7 | 服装必须有角色依据，不得全员默认灰黑 |
| R8 | 皮肤真实但上镜，干净健康，不做蜡像磨皮 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣、暴露、透视、性化打底 |
| X2 | 疲惫苦相、病态瘦、脏乱邋遢，除非事实源明确要求 |
| X3 | 无依据黑色/深灰 T 恤和同质化牛仔裤塌缩 |
| X4 | 工作场景、情绪场景、剧情动作、影视镜头 |
| X5 | 正顶硬光、正底光、彩色舞台光 |
| X6 | 过度美白、过度磨皮、网红脸、强妆容 |
| X7 | 四视图间面容、发型、服装不一致 |
| X8 | 人像特写使用微侧脸、三分之二侧脸、侧脸、回头、低头或仰头角度 |
