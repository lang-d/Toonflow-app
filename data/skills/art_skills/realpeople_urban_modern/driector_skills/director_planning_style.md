# 都市写实导演规划手册

本手册只负责“导演规划层”的表现方法，不决定剧情事实、角色关系或资产内容。

## 一、职责边界

- 只给段落级视觉、空间、节奏和声音方向。
- 不把风格词直接传给图片 prompt 或视频 prompt。
- 不覆盖剧本、资产设定、参考图和项目参考包中的硬事实。
- 不逐镜指定光影色调；逐镜画面由分镜表、参考图和生成阶段处理。

## 二、色彩与光线方法

导演规划只选择“段落级色彩/光线方向”，用于后续统一，不作为逐镜强制词。

| 方向 | 可执行描述 | 适用段落 |
|---|---|---|
| 生活自然光 | 5200K-5800K，室内窗光或日间环境光，低戏剧化阴影 | 家庭、学校、日常任务 |
| 冷白功能光 | 顶灯、走廊灯、电梯灯、办公室灯，色温偏冷但不过度蓝 | 系统派单、通勤、规则压力 |
| 局部暖光 | 台灯、厨房灯、便利店暖光、傍晚斜光 | 关系缓和、短暂安全感 |
| 阴天漫射 | 阴天或雨前散射光，低反差，灰蓝倾向 | 低潮、等待、犹豫 |
| 夜间城市混合光 | 路灯、店招、车灯、窗内光混合，保持写实 | 夜路、转场、城市孤独 |

使用规则：

- 每个段落最多选择 1 个主方向和 1 个辅助方向。
- 光线方向必须能从场景资产或剧情时段中成立。
- 有参考图时，参考图事实优先；导演规划不能重写参考图光影。
- 禁止把“高级灰、电影感、极致细节、氛围拉满”作为可执行方案。

## 三、摄影与空间方法

导演规划重点写“为什么用这种距离和空间关系”，不写逐镜分镜表。

| 叙事目的 | 推荐方法 |
|---|---|
| 建立环境压力 | 大全景/全景先建立空间，人物置于中景或背景压力中 |
| 强化关系距离 | 中景保留两人之间的桌子、门框、走廊、栏杆等阻隔 |
| 进入角色内心 | 近景或特写收紧，同时写清视线、呼吸、手部细节 |
| 对话交锋 | 正反打或过肩视角，守住视轴，避免无意义乱切 |
| 情绪转折 | 景别骤变、动作骤停、空间遮挡消失或出现 |
| 关系缓和 | 距离变近、遮挡减少、同框比例增加 |

空间元素参考：

- 门洞、窗框、玻璃、电梯门、走廊尽头：用于空间分层和心理距离。
- 餐桌、课桌、柜台、栏杆、车窗：用于关系阻隔。
- 手机、快递箱、票据、旧手表等道具：只在剧本或资产已有时作为动作锚点。
- 不要为了“画面丰富”新增剧本和资产中没有的物件。

## 四、质感与表演方向

写实质感应服务表演和资产连续性，不输出空泛画质词。

- 人物：写可见表演出口，如视线躲开、手指攥紧、肩膀放松、呼吸停顿、语气放轻。
- 场景：写空间功能和使用痕迹，如冷白顶灯、磨损扶手、拥挤货架、潮湿地面。
- 道具：写状态和用途，如屏幕裂纹、边角磨损、贴纸残留、金属反光。
- 皮肤和服装质感只在需要说明状态时出现，例如“熬夜后眼下轻微暗沉”“旧衣袖口磨白”；不要写“毛孔级”“发丝根根分明”“极致细节”。

## 五、声音与配乐方向

声音分三层处理：

| 层级 | 用途 | 写法 |
|---|---|---|
| 画内环境音 | 可进入分镜表音效列 | 电梯提示音、市场叫卖、手机震动、雨滴檐角、楼道回声 |
| 动作音 | 跟随具体动作 | 纸箱摩擦、钥匙碰撞、脚步停住、门锁咔哒 |
| BGM 后期方向 | 只给剪辑和后期参考 | 乐器倾向、节奏密度、情绪弧线、进入/退出位置 |

BGM 参考：

- 日常推进：钢琴或木吉他，节奏轻，不能盖过对白。
- 压力/规则感：低频铺底或极简电子脉冲，少旋律。
- 情绪缓和：钢琴加轻弦乐，音量后置。
- 夜间城市：轻电子或 lo-fi 质感，和环境声并存。

硬边界：

- BGM 不进入分镜表音效列。
- BGM 不写入图片 prompt 或视频 prompt。
- “悲伤音乐、紧张音乐、治愈音乐”必须转成乐器、节奏、音量和进出点。

## 六、导演规划输出建议

- 每场至少写 1 个空间关系、1 个表演出口、1 个环境声。
- 每个段落的视觉方向要能被后续归纳为场景状态或资产状态。
- 需要多视角拍摄的场景，应在导演规划中说明叙事理由，便于衍生资产预划判断。
- 禁止让风格手册反向改写剧情事实、资产设定或参考图。
