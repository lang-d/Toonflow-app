# 真人专业纪实写实 · 角色基础资产

## 职责与方法

`assetFoundation` 读取面容、体态、发型、身份、基础服装、确认制服/证件/防护和锚点；`visualDesignRationale` 负责识别度、可信职业轮廓和可行动性。真实骨相肤质、自然体态、服装层级与面料结构优先；没有事实时不加入警服、白大褂、法袍、工牌、手套或装备。基础状态不预设疲劳、伤病、污渍和英雄姿态。

## 类型专属设计方法

- 真实面容保留年龄、骨相、肤质和自然不对称，体态来自已确认人物而非职业英雄化模板。
- 服装按贴身层、日常层、职业外层和防护层拆分，说明开合、口袋、活动余量和面料；制服只在事实确认时出现。
- 证件、徽记和防护用品分别说明归属、佩戴位置、固定方式与可见范围，不用它们推导职位、权限或机构。
- 发型与配件服从实际工作动作和确认规范，不自动添加利落短发、眼镜、手套或通讯设备。
- 头像与正侧背全身保持面容、肩宽、衣长、层级、证件位置和鞋履一致，使用中性站姿验证可行动性。

## 提示词模板（编译顺序）

```text
真人专业纪实写实角色基础设定图，character design sheet；{身份、面容、体态、发型、基础服装、确认职业服饰与锚点}；真实骨相肤质、自然比例、明确服装层级，仅呈现确认的制服证件防护用品；头像 + 正侧背全身四视图，同一人物完整一致；中性自然窗光、真实皮肤织物塑料金属中实际材料；中性灰；无工作现场、剧情动作、默认职业制服设备、英雄海报姿态、文字水印。
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

XML 流程写入 `<assetImagePrompt>`，否则只返回最终提示词；不得残留占位项或新增职业、权限、品牌和设备。

## 必守与严禁

必须生成稳定可复用的人物设定图。严禁默认警服、白大褂、法袍、证件、防护用品、英雄光、工作现场、剧情动作和用制服替代人物事实。
