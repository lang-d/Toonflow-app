# 真人专业纪实写实 · 角色衍生资产

## 职责与方法

`assetFoundation` 锁定人物和基准服装轮廓，指定唯一制服层、防护、证件、发型、疲劳、伤病或污渍变化；`visualDesignRationale` 保持识别与材料因果。变化不得扩大职位、权限和剧情，也不得同时更换整套身份系统。

## 类型专属设计方法

- 锁定人物骨相、体态、发际线、基准服装轮廓和既有身份锚点，参考图优先于类型惯例。
- 把制服层、防护层、证件、发型或身体状态分别视为独立变化；一次只能选择其中一项和明确部位。
- 穿脱外层时内层与体态不变；防护用品按真实固定点和覆盖区出现；证件变化不得改变姓名、机构、职位或权限。
- 疲劳、污渍或伤病只按事实呈现可见程度，不通过夸张姿势、强硬表情或英雄化损伤扩写职业剧情。
- 四视图保持唯一变化的部位、层级和程度一致，不把“工作后状态”同时解释为汗湿、污损和伤病。

## 提示词模板（编译顺序）

```text
真人专业纪实写实角色衍生设定图，same person as reference image；稳定事实：{基准面容、体态、发型、服装轮廓和身份锚点}；设计理由：{保持识别度与职业可信度的处理}；本次唯一变化：{确认的单一职业服化、防护或状态变化}；专业细节：变化仅作用指定层与部位，符合织物、防护材料、皮肤和配件结构；视图与构图：头像 + 正侧背全身四视图，变化一致；光线材质：中性窗光；背景：中性灰；禁止项：不换人、不升级职位权限、不加第二变化、场景设备、英雄姿态、文字水印。
```

## 输出规则

XML 写入 `<assetImagePrompt>`，否则只返回提示词；事实不足时保持基准人物。

## 必守与严禁

必须明确同一人物、不可变锚点和唯一变化。严禁升级职位权限、更换机构身份、增加第二套装备、场景设备、剧情动作、宣传姿态或无依据文字标识。
