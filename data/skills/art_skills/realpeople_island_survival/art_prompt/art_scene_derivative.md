# 真人荒岛求生 · 场景衍生资产

## 职责与输入契约

生成同一基准地点的衍生设定图，不生成新地点或重构空间。`assetFoundation` 读取基准场景的结构、布局、海陆方向、出入口、地标、材质和不可变锚点，以及本次唯一允许变化的视角、景别、时段、天气或已确认状态。`visualDesignRationale` 负责维持地点识别和光色逻辑；不得新增营地、资源、人物、灾害或剧情。

## 设计方法

- 始终写明 `same location`，保留相同地形轮廓、潮线关系、入口出口、地标和主要材质。
- 视角或景别变化不等于空间重构：新机位要通过至少两个既有地标、海陆方向、入口出口或路线关系证明仍是同一地点；不得让海岸、礁石或营地结构消失、互换或扩建。
- 时段变化只重算已确认太阳高度、色温、阴影和可见范围；天气变化只重算云层、对比度、风雨痕迹和表面反射；潮位变化只移动已确认潮线并改变被淹或裸露范围；状态变化只触及已指定物件或区域。一次只选择其中一类。
- 材质连续必须可比较：同一沙地、岩面、植被、水面或人工材料保留纹理和位置，湿润、干燥、盐渍或损坏只有本次事实指定时才改变。不能用滤镜把同一地点变成另一气候带。
- 场景识别优先于氛围差异：保留固定布局、危险边界和通行面，光源方向符合时段与遮挡，天气或潮位不得创造新路线和新地点。
- 无人物、无行动，避免把场景衍生误写成剧情截图。

```text
真人荒岛求生题材场景衍生设定图，same location；稳定事实：{assetFoundation 中基准地点的地形轮廓、固定布局、海陆方向、入口出口、连续性地标、通行面、危险边界和主要材质}；设计理由：{visualDesignRationale 中保持地点识别与空间连续的处理}；本次唯一变化：{assetFoundation 已确认的单一视角、景别、时段、天气、潮位或地点状态变化}；专业细节：只重算该变化引起的可见范围、光色、阴影、表面干湿或已指定状态，其他布局和材料保持；视图与构图：前景 + 中景 + 后景维持同一空间关系，以至少两个既有锚点证明同一地点；光线材质：可追溯自然或已确认现场光，真实海岛材料响应；背景与环境：不越出基准地点边界；禁止项：无新地点、空间重构、第二种状态变化、人物、剧情事件、未确认资源工具、动物、救援物、文字、水印、签名或无依据标识。
```

## 输出规则

- 资产基础设定流程中，外层 XML 契约优先，将最终提示词写入 `<assetImagePrompt>`。
- 直接润色或后台任务调用时，只输出最终提示词正文，不输出 XML、Markdown、分析、表格或模板说明。
- 最终不得残留花括号占位项；无法确认变化范围时保持基准场景。

## 必守与严禁

- 必守：同一地点、同一结构与连续性锚点；仅改变一次已确认状态。
- 严禁：新地点、新人物、空间重构、未经确认的潮汐、风暴、营地损坏或救援痕迹。
