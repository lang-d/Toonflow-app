# 真人荒岛求生 · 角色衍生资产

## 职责与输入契约

生成同一基准角色的衍生设定图，不生成新人物或完整剧情画面。`assetFoundation` 读取基准角色的不可变身份、面容、体态、发型、基础服装轮廓、配件和连续性锚点，以及本次已确认的唯一变化。`visualDesignRationale` 说明如何让变化可读而不破坏人物识别度；不得扩大变化范围，不得新增未经确认的地点、工具、关系和事件。

只有剧本或已确认资产明确时，才允许变化为服装层级、发型、妆容、配件、表情、湿度、污渍、伤病、晒伤、疲劳或已携带物。若变化涉及伤病、湿衣或求生装备，必须写明来自哪项确认事实；没有确认时保持基础状态。

## 设计方法

- 始终写明 `same person as reference image`，保留相同脸型、五官比例、体态、年龄感和不可变识别特征。
- 本次唯一变化：服装/发型/妆容/配饰/表情或状态。变化只落在事实指定的身体区域、服装层或配件，不由一个局部状态扩散成全身灾难妆。
- 湿度使发丝结束、布料色深与垂坠改变；盐渍形成干燥边缘和细小结晶；泥沙按接触面附着；磨损沿缝线、边缘或受力点出现。只有事实确认相应状态时才选择这些表现。
- 伤病只表现已确认位置、外观和活动限制，不添加伤口程度、血迹、绷带或治疗；发型与服装变化只改指定层，身份服装的核心轮廓仍须可辨。
- 保持真人自然光和真实织物、皮肤、发丝对本次变化的材料响应；不把衍生图放进海岸、营地或行动现场。
- 四视图中变化程度、物件位置和身体状态一致，避免换脸、换体态、换人或加入剧情动作。

## 提示词模板（编译顺序）

```text
真人荒岛求生题材角色衍生设定图，same person as reference image；稳定事实：{assetFoundation 中基准人物的不可变身份、面容、体态、发型结构、服装核心轮廓、配件和连续性锚点}；设计理由：{visualDesignRationale 中保持识别度且不扩大变化的处理}；本次唯一变化：{assetFoundation 已确认的单一服装、发型、妆容、配饰、表情或状态变化及其限定区域}；专业细节：按事实选择湿度、盐渍、泥沙、磨损、伤病、发型或服装状态的真实材料响应，未确认项不出现；视图与构图：正面头像特写 + 正面全身 + 侧面全身 + 背面全身，四视图变化范围和程度一致，完整不裁切；光线材质：柔和可追溯自然窗光，真实皮肤、发丝与织物；背景：摄影棚中性灰；禁止项：不换人、不改体态年龄和身份锚点，不扩展第二种变化，不增加地点、剧情动作、无依据工具配件、文字、水印、签名或可读标识。
```

## 输出规则

- 资产基础设定流程中，外层 XML 契约优先，将最终提示词写入 `<assetImagePrompt>`。
- 直接润色或后台任务调用时，只输出最终提示词正文，不输出 XML、Markdown、分析、表格或模板说明。
- 最终不得残留花括号占位项；变化事实不完整时只保留可确认部分。

## 必守与严禁

- 必守：锁定同一人物，且每次只呈现一个已确认的变化范围。
- 必守：伤病、浸湿、晒伤、污渍和工具均须有明确事实来源。
- 严禁：换脸、改体态、改变年龄、添加新人物、地点、功能或未确认求生情节。
- 严禁：把“荒岛求生”当成自动附带伤口、破衣、木筏或武器的设定。
