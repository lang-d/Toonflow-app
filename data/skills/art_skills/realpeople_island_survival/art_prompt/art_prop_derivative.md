# 真人荒岛求生 · 道具衍生资产

## 职责与输入契约

生成同一基准道具的衍生设定图，不生成替代道具或新功能。`assetFoundation` 读取基准道具的用途、尺寸、轮廓、结构、材料、颜色和不可变识别锚点，以及本次已确认的唯一状态或角度变化。`visualDesignRationale` 说明怎样让变化符合材料的物理因果而保持识别；不得用类型想象补充新功能、资源或剧情。

## 设计方法

- 始终写明 `same object`，保持同一轮廓、结构、比例、颜色和核心用途。
- 变化可为已确认角度、开启/关闭、湿润/干燥、盐渍、砂粒、锈蚀、裂纹、修补或缺损；每次只选一项，且需有明确事实来源。简化衍生只比较基准状态与该变化，不扩写产生它的剧情。
- 湿润使表面颜色、反射或纤维重量变化，干燥恢复哑光并可能留下已确认水痕；盐渍沿蒸发边界结晶；砂粒只附着于接触或潮湿区域；锈蚀只作用于可锈金属和事实指定位置。
- 裂纹须服从材料受力与纹理方向；修补须使用已确认材料并保留原结构；缺损只移除指定部分；开启状态只移动既有铰链、盖体、扣件或拉链。不得因变化新增零件、用途或容积。
- 颜色变化应是材料状态的局部结果，不能把整个道具重配色。标识、接缝、紧固件和磨损锚点在所有视图中保持位置一致。
- 保持静物设定图，不出现人物、手、营地、使用动作、品牌宣传或新物件。

## 提示词模板（编译顺序）

```text
真人荒岛求生题材道具衍生设定图，same object；{基准道具的用途、尺寸、轮廓、结构、材料、颜色、标识、接缝和不可变识别锚点}；本次仅呈现{已确认的单一角度、开合、湿润、干燥、盐渍、砂粒、锈蚀、裂纹、修补或缺损状态}；变化只作用于事实指定部位，符合该材料的吸水、蒸发、附着、氧化、受力或连接逻辑，轮廓结构颜色用途保持；正面 + 侧面 + 背面或底部 + 变化部位材质特写，完整物体可见且变化程度一致；柔和自然窗光、真实表面响应与接触阴影；中性灰静物；不换物、不增加零件功能或第二种状态，无人物、手持、使用动作、营地海岸剧情、品牌、文字、水印、签名或无依据标识。
```

## 输出规则

`visualDesignRationale` 只在编译时转译为可见的造型、结构、布局、材质或状态结果；最终图片 Prompt 不得输出字段名、栏目名、分析理由或占位符。

- 资产基础设定流程中，外层 XML 契约优先，将最终提示词写入 `<assetImagePrompt>`。
- 直接润色或后台任务调用时，只输出最终提示词正文，不输出 XML、Markdown、分析、表格或模板说明。
- 最终不得残留花括号占位项；状态来源不明确时只保留基准事实。

## 必守与严禁

- 必守：同一道具、同一用途、同一结构和颜色，只呈现已确认的一次变化。
- 严禁：不换物、不新增功能，不增加求生装备、人物、手持、剧情现场、品牌或无依据文字。
