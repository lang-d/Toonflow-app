# 视频提示词生成 Skill：Seedance 2.0

把结构化分镜和多模态参考编译成 Seedance 2.0 中文视频提示词。不要复述分镜表或补写导演分析。

## 素材职责

每个 `<trackStoryboard>` 提供版本、时长、起点、运镜、台词、声音和原生时间事实：V3 使用 `shotDescription`；历史 V1/V2 使用 `action`，无正式分镜图时才使用 `picture`。

- `visualStart=storyboardReference`：只有引用清单中存在与当前 `storyboardId` 对应的图片 token，才能写“`@ImageN` 作为本镜首帧，随后……”。该图是本镜唯一初始视觉依据；不用文字复述人物站位、景别、机位、构图、布局或初始姿态。V3 只组织图后变化和结尾，历史 V1/V2 从图中状态执行 `action`。
- `visualStart=textFallback`：V3 使用完整 `shotDescription`、`shotSize` 和必要 `cameraAngle` 建立起点及后续变化；历史 V1/V2 使用 `picture + shotSize` 建立起点，再执行 `action`。即使引用清单中有角色图、场景图、道具图或合图，也不得写“沿用 `@ImageN`”或“以 `@ImageN` 开拍”。
- 普通资产图只承担引用清单确认的外观或合图职责，不能自行升级为某条分镜的首帧。只使用已有 `@ImageN`，不得改变编号、名称和职责。
- 音频写“参考音频N”，视频写“参考视频N”，不占用 `@ImageN`，不扩大已有职责。
- 不要查找或推断 `visibleEmotion`、`characters[]`，不从字段名、来源名或素材顺序创造事实。

## 时间编译

`shotDescription` 是 V3 的唯一时间事实正文。保持最早状态、触发、连续变化和结束状态的原顺序；有正式分镜图时省略已经由首帧成立的最早状态，只写图后变化。已明确的视线、表情、呼吸、手部或姿态变化，按其发生时段执行，不要另行设计一套情绪表演。

按输入顺序和各自 `duration` 逐镜编译，不额外拆分时间段，不新增镜头、转场或其他组内容。可重组为“主体与起点 → 连续动作/变化 → 结束状态 → 必要运镜、台词和画内声音”，压缩重复并强化动作；不得增加表演、环境事件、镜头切换或素材职责。

`dialogue` 逐字保留；`voiceTone` 只转成音量、语速、气息、停顿和尾音，不推断或新增视觉表情。`sound` 只作画内声音，`cameraMove` 非空才写。禁止添加 BGM、配乐、OST 或主题音乐。

有正式 `videoStyle` 时首行原义使用，不二次扩写，不加入场景、天气、人物、动作、画质词或模型参数。可为 Seedance 2.0 重组、压缩和强化提示语，但不得替换或反转人物/物件、空间方向、动作结果、时间顺序与因果。

## 输出

只输出中文视频提示词正文，不输出 Markdown、XML、JSON、分析、审校建议、内部字段名或来源判断。

有对应分镜图时，镜头正文以“`@ImageN` 作为本镜首帧，随后……”自然承接图后变化；无对应分镜图时，直接写主体、起点和后续变化，不写“依据”“回退”“沿用素材”等说明。

```text
画面风格和类型：{有正式 videoStyle 时原义使用；没有时省略}

参考定义：
@Image1：{素材名}，用于{引用清单已经确认的职责}

分镜1（{duration}s）：
{按本镜首帧状态和时间事实编译的自然语言正文}
台词：{逐字台词与已有文字音色；无则省略}
相机：{已有 cameraMove；无则省略}
画内声音：{已有 sound；无则省略}
```

## 自检

- 只有与当前 `storyboardId` 对应的正式分镜图是否被写成该镜首帧；
- 没有正式分镜图时是否直接建立画面，没有把普通资产图写成首帧；
- V3 是否只以 `shotDescription` 组织时间过程，历史 V1/V2 是否保持版本原生字段；
- 分镜顺序、时长、台词、文字音色和画内声音是否完整且没有新增；
- 最终正文中的 `@ImageN` 是否与可用 token、素材名称和职责完全一致。
