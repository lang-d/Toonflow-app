# H3 single-shot expression skill: music-video typography

## Scope and fact inheritance

Use this layer only for a supplied shot that already contains an explicit lyric, dialogue, visible text, timed music/audio reference, performance, or typography fact. It is not a lyric-writing, song-analysis, beat-detection, character/scene-card, multi-shot stitching, BGM-generation, editing, or subtitle-burn-in workflow. Do not treat a type selection as proof that a song, singer, lyric, subtitle, beat, choreography, transition, or performance exists.

Preserve all dialogue, lyrics, on-screen text, speakers, supplied timing, reference roles, and formal `videoStyle` verbatim. Do not translate text, correct wording, or promote ordinary dialogue into a lyric graphic. The no-BGM rule remains authoritative even if the official MV workflow normally works from a music bed.

## Typography and rhythm grammar

When exact visible text is supplied, treat it as a designed spatial visual layer rather than an automatic lower-third caption. Bind the text to its stated speaker, moment, composition, and existing movement; keep it readable and avoid covering the confirmed focal subject. Use a text entrance, hold, replacement, or exit only when the shot facts or reference composition support it. Preserve one readable visual message at a time unless multiple text blocks are explicitly supplied.

When a timed audio/lyric fact exists, align existing action, camera emphasis, or typography change to that stated cue. When only dialogue exists, keep it in dialogue timing rather than inventing musical beat cuts. Camera language must serve the confirmed performance, text, or emotional event; never add choreography, concert coverage, reaction cuts, or transitions as a preset.

## Timeline compilation

Write the shot in chronological intervals: establish the supplied performer/scene/text state -> place each confirmed spoken, sung, or visible-text event at its real moment -> carry the existing action and camera to the stated end state. For longer groups, retain each supplied shot boundary and duration; this layer does not create a music-video montage or re-sequence shots. If text timing is absent, preserve text only as a factual visual element and do not invent beat-sync animation.

`overall_soundscape` describes only supplied ambience, physical sound, dialogue, sung lyric, or diegetic music. It must not add a score, instrumental bed, vocal track, crowd, or audience reaction.

## Missing-fact policy and boundaries

Without explicit lyric/text/audio timing, omit typography choreography and rhythmic cut language. Without a confirmed performer, omit singing and performance direction. Never invent lyrics, subtitles, fonts, titles, music genre, BGM, choreography, or an emotional story beyond the shot facts.

Do not override the formal `videoStyle`, chronology and duration, keyframe/reference roles, media labels, dialogue, visible text, diegetic sound, or the no-BGM rule.

## Final check

Every graphic or rhythmic instruction must point to an existing text, audio, or visual event. The finished Prompt must read as a single evidence-based shot, not as a generic MV preset.
