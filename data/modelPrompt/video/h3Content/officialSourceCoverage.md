# MiniMax H3 type-skill source coverage

This is a non-runtime audit record. `profileMap.json` loads only the selected file in this directory; this document is never sent to the prompt compiler.

## Adaptation rule

Each official Skill was read in full, including the linked runtime templates and production references where present. Toonflow already owns project intake, script, director plan, V3 storyboard, asset derivation, reference mapping, video dispatch, and assembly. The runtime adaptations therefore retain only rules that improve one established storyboard shot. They never recreate source research, user gates, asset creation, narrative rewrites, multi-shot planning, music generation, editing, or delivery.

## `minimalist-product-ad`

- **Official source:** `skills/minimalist-product-ad-generator/SKILL.md`: Operating Principles, Typography Rules, Steps 3–8.
- **Retained for one shot:** product identity/colour/material fidelity; one visual lead; real structure-driven motion; primary-before-secondary timing; readable settle; supplied-copy-only typography; no grids, product walls, fake UI, empty opening, or unsupported claims.
- **Excluded:** product selection, variant decisions, English copy generation, three anchor photos, campaign beat table, music and assembly. Toonflow must not create product facts or send a commercial workflow when it has only one factual shot.

## `3d-animation-short`

- **Official source:** `skills/3d-animation-short-generator/SKILL.md` Steps 5–7; `references/shot-table-spec.md`; `references/storyboard-guidelines.md`; `references/qc-checklist.md`.
- **Retained for one shot:** opening-to-ending spatial handoff; pose/silhouette/contact/weight clarity; evidenced anticipation, action, overshoot, follow-through and settle; per-duration continuous action; camera motivated by the primary action.
- **Excluded:** its default Pixar style, character/scene cards, hook taxonomy, six-column table, mandatory per-second production artifact, storyboard panels, model choice, retries, BGM and assembly. They either conflict with the formal `videoStyle` or are already upstream/downstream Toonflow responsibilities.

## `papercraft-stop-motion`

- **Official source:** `skills/papercraft-stop-motion-explainer/SKILL.md`: Visual Depth and Papercraft Motion Priority; Steps 6, 11, 14–16, 18–19.
- **Retained for one shot:** layered foreground/midground/background; visible paper construction and mechanisms; stepped motion, pauses and rebound; material-led camera and factual tactile SFX.
- **Excluded:** topic/learning-goal extraction, creative directions, character/scene/prop redesign, previews, narration, full storyboard, transitions, voice-over and review package. A user-selected type cannot rewrite the existing story or medium.

## `brand-promo`

- **Official source:** `skills/brand-promo-video-generator/SKILL.md` Steps 2–6 and 9.
- **Retained for one shot:** verifiable asset truth, one communication focus, fact-led reveal/action/result, exact supplied UI/copy/mark handling, a clear readable hold.
- **Excluded:** source research, truth sheet creation, provenance collection, campaign/audience/CTA design, new images, speech/music, assembly and delivery. Unverified marketing claims are forbidden in Toonflow.

## `mv-subtitle`

- **Official source:** `skills/mv-subtitle-skill-confirmed/SKILL.md`: Core principles, reference roles, typography packaging, prompt structure, checklist.
- **Retained for one shot:** exact lyric/dialogue/text preservation; text as a spatial layer rather than default subtitles; timing only from supplied sound/text facts; stable speaker/text/camera continuity.
- **Excluded:** lyric generation, beat analysis, music-window selection, global audio continuity, multi-shot stitching, BGM generation and assembly. Toonflow's standing no-BGM constraint is stronger than the source's music workflow.

## `co-op-game-intro`

- **Official source:** `skills/co-op-game-intro-generator/SKILL.md`; `references/h3-confirmation-image-template.md`; `references/h3-video-prompt-template.md`.
- **Retained for one shot:** two-subject identity and spatial relation; verified UI hierarchy; one confirmed shared UI/event progression; exact supplied game text.
- **Excluded:** fixed menu framework, confirmation-image generation, player-name/title collection, default palette, button/icon/menu invention, repair loop. They require assets and facts not guaranteed in a storyboard shot.

## `paper-collage-explainer`

- **Official source:** `skills/paper-collage-explainer-generator/SKILL.md`: Default Creative Targets, Global Style Rules, still-frame and stop-motion assembly steps, review.
- **Retained for one shot:** supported halftone/cut-out/cardstock grammar; focal depth; tactile staged assembly; fact-tied paper SFX; no automatic BGM, narration, or subtitles.
- **Excluded:** topic-to-metaphor invention, production plan, still generation, narration, full clip assembly and quality package. A type setting never changes a non-collage `videoStyle`.

## `handdrawn-live`

- **Official source:** `skills/handdrawn-live-video-generator/SKILL.md` Steps 1–4.
- **Retained for one shot:** explicit contact; same-entity continuous morphing; one connected real space; delayed camera follow when compatible; rough drawn material only when already established; non-horror boundary; duration-proportional staging.
- **Excluded:** fresh premise invention, forced 15-second/16:9 structure, mandatory hand/chase/ending, new live-action location, and the source's fixed creative-form choices. Toonflow preserves the existing shot duration and facts.
